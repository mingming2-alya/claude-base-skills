# remotion-dev/skills: competitor deep-dive

> Subagent report, 2026-11-11. Studied at commit `1af7e69a2a613437d46095924057970a6a7df40d`. Paths are relative to the repo root.

Remotion Agent Skills is a manual for building videos in Remotion, not a style or film library. It competes for the same agents and the same "make a video" requests, but has no direction workflow, no styles and no built-in audio pipeline.

**1. Metadata**
- 6,811 stars, 736 forks, 23 open issues. Created 2026-01-19; last push 2026-11-09.
- TypeScript. No licence detected and no LICENSE file. No topics.
- Generated from the main Remotion repo's `packages/skills` (`package.json` repository URL; `README.md` header says it is generated by `sync-readme.ts`). Package `@remotion/skills` v4.0.542.

**2. Positioning**
- "Agent Skills that define best practices for working in Remotion projects" (`README.md`).
- Target: developers using Remotion, or new users starting a project through an agent ("Make a promo video for a record store").

**3. How it works**
- Videos are React components; every animation driven by `useCurrentFrame()` and `interpolate()`; CSS animations won't render (`skills/remotion-markup/SKILL.md`).
- Rendering via Remotion's headless Chrome (`npx remotion render`/`still`; `--frames` for single frames) (`skills/remotion-render/SKILL.md`).
- Scaffold with `npx create-video@latest --yes --blank` (`skills/remotion-create/SKILL.md`).
- Install: `npx skills add remotion-dev/skills`, `gh skill install remotion-dev/skills`, or via `bun create video`.
- `remotion-best-practices` is a router with embedded copies of the others (`scripts/sync-embedded-skills.ts`).
- The agent opens Remotion Studio before building and renders only when the user asks explicitly.

**4. Content scope**
- 13 skills: best-practices, create, markup, studio, render, maps, captions, saas, interactivity, docs, license, upgrade, multimedia.
- ~77 rule/reference files without duplicates (markup 49, maps 14, others 0–3).
- Topics: compositions, sequencing, transitions, 3D (Three.js), Lottie, GIFs, fonts, text highlights, motion blur, ~80 built-in effects, colour/LUT grading, video matting, RTL text, maps (Mapbox, MapLibre, MapTiler, Cesium), Zod-parameterised videos, apps (Lambda, Vercel, Cloudflare).
- No named film styles and no demo films.

**5. Audio**
- Voice: ElevenLabs TTS by default (API key); length sized to voiceover via `calculateMetadata` (`skills/remotion-markup/voiceover.md`).
- Music: only placing/editing tracks; nothing composes a score (`audio.md`, `video-editing.md`).
- SFX: 32 hosted meme/UI clips at remotion.media plus "search the internet" (`sfx.md`). No foley design.
- Captions: local Whisper on GPU via `@remotion/whisper-webgpu`, SRT import, Basic Captions component (`skills/remotion-captions/*`).
- No loudness standard and no voiceover-vs-script check.

**6. Workflow and quality controls**
- Visual checks in Studio plus optional single-frame renders.
- Layout rules: safe areas, minimum text sizes, "you are designing a video, not a webpage" (`skills/remotion-create/video-layout.md`).
- "Preserve user changes" made outside the chat.
- No treatment, shot list, cue map or self-check checklist.

**7. Customization**
- Studio editing writes back to code; markup structured to stay editable (`skills/remotion-interactivity/SKILL.md`).
- Custom effects via `createEffect()`; Zod parameterisation. No saved-style concept.

**8. Compatibility**
- Claude Code, Codex, Kimi Code, Cursor; `agents/openai.yaml` per skill. Not tuned to one model.

**9. Requirements and cost**
- Node.js and Git; GPU for Whisper captions (no Linux arm64). Optional paid keys: ElevenLabs, Mapbox, MapTiler. Possibly a Remotion company licence.

**10. Licensing**
- No licence file; the `remotion-license` skill only links to remotion.dev/docs/license, FAQ, terms, remotion.pro/license.
- *General knowledge, not in the repo:* the Remotion License is free for individuals, non-profits and companies up to 3 employees; larger for-profit companies need a paid Company License.
- remotion.media sound clip terms not stated; several are copyrighted meme sounds.

**11. Strengths vs. lemo-opuscar**
- Official and maintained by the Remotion team; mature framework with Studio and timeline editing; large effects library; maps and 3D; footage editing; server/app rendering; many agents; docs-search skill keeps the agent on the current API.

**Weaknesses vs. lemo-opuscar**
- No style library, demo films or direction method; no procedural music, foley, free local TTS by default, voiceover check or loudness mastering; doesn't deliver an MP4 by default; commercial licence cost for larger companies; meme SFX of unclear licence.

**12. Same-nature fit: 3/5.** Overlaps directly on intent and agents, but is framework know-how without curated styles, film-direction workflow or a built-in sound pipeline.
