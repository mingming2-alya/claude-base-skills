# 3D 產業鏈地圖與 EPM 模擬遊戲：應用場景發想

- **狀態**：等使用者決定（選定要落地的場景）
- **日期**：2026-11-09（2026-11-11 回溯補登）

## 目標
使用者對兩個專案的概念與技術架構有興趣，想探索可以套用的場景。

## 做了什麼
1. 派 web-fetch 子 agent 讀取兩個網站，兩者都因會話網路允許清單未包含該網域而失敗（`ENOTFOUND`），**未實際看過網站內容**。
2. 依使用者描述與常見做法，拆解兩者的共同模式、可能的技術組合，並提出應用場景與下一步選項。分析見 `outputs/應用場景分析.md`。

## 決策紀錄
- 抓取失敗後沒有憑記憶臆測網站細節，在回覆中明確標示「沒親眼看過，技術選型是推測」。

## 產出物
- `outputs/應用場景分析.md`

## 輸入物
- `inputs/需求原文.md`

## 下一步（等使用者選）
1. 選一個產業或職位，做可互動的 3D 結構圖或小型工作模擬原型
2. 設計節點／任務的資料格式
3. 整理成提案文件
- 若要實際分析網站：把 `learninvest.co`、`rw-code-tw.github.io` 加入環境網路允許清單，或提供截圖、原始碼。
