# 3D 產業鏈地圖 × EPM 一日工作模擬：拆解與應用場景

> 注意：兩個網站在當時的會話網路設定下無法開啟，以下依使用者描述與常見做法推論，具體實作可能不同。

## 兩個專案的共同點

| | 3D 產業鏈地圖 | EPM 一日工作模擬 |
|---|---|---|
| 抽象的東西 | 供應鏈上中下游、零組件之間的關係 | 一個職位的工作流程與各課分工 |
| 轉換方式 | 把元件做成 3D 模型，可拆解、點擊 | 用遊戲角色走一遍，透過任務互動 |
| 學習方式 | 用空間理解結構 | 動手做過，理解流程 |
| 底層模式 | 資料驅動的可視化（節點＋關係＋說明） | 劇本驅動的模擬（場景＋任務＋回饋） |

常見技術組合（推測）：
- 3D 地圖：Three.js 或 React Three Fiber，模型用 glTF/GLB；內容放 JSON（節點、上下游、廠商、說明），前端只負責顯示。
- 模擬遊戲：Phaser 或純 Canvas 做 2D 場景，任務與對話寫成設定檔；部署在 GitHub Pages，零成本。
- 關鍵是**內容和引擎分開**：換一份資料就能做另一個產業或職位。

## 可延伸的應用場景

**用 3D 拆解結構**
- 新人訓練：產品（伺服器、手機、車用模組）的可點擊 3D 爆炸圖，零件連到負責部門或供應商。
- 銷售與客戶簡報：互動式產品架構說明。
- 投資研究：把財報、法說會資訊掛在產業鏈節點上。
- 風險管理：標出單一供應來源與地緣風險，做斷鏈模擬。

**用模擬體驗流程**
- 招募：讓應徵者試玩這份工作，降低期待落差。
- 跨部門理解：業務、RD、PM 互玩對方的一天。
- SOP 與合規訓練：有分支的情境題，選錯看到後果。
- 校園推廣與產業教育。

**兩者結合**
- 在 3D 產業鏈點某節點，進入該環節的一日工作模擬。
- 加上 LLM：自動產生節點說明、任務劇本，或在遊戲中扮演主管、客戶即時對話，降低內容擴充成本。
