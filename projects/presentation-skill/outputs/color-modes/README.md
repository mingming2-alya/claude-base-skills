# 明暗兩版配色（Apple 發表、顧問報告）

_2026-11-19。使用者決定底色明暗不定死：_

- _Apple 發表的深色舞台很好，但也要有淺色底。_
- _顧問報告的淺色紙很好，但也要有深色底。_

`sheet.jpg` 是十二張的對照：2 款 × 2 種底 × 3 組配色。

| 風格 | 底 | 三組配色 |
|---|---|---|
| Apple 發表 | 深色舞台（原有） | 暖橘、冰藍、翠綠 |
| Apple 發表 | 淺色舞台（新） | 暖橘、冰藍、翠綠（漸層加深，維持 3:1） |
| 顧問報告 | 淺色紙（原有） | 綠、藍、墨黑 |
| 顧問報告 | 深色石板（新） | 綠、藍、紙白 |

## 做法

- `tpl/apple.html`、`tpl/counsel.html`：版面只有一份，所有顏色都是角色變數，例如舞台、主文字、主漸層、焦點色、警示色。
- `make.py`：依「底 × 配色」寫出十二個變體到 `src/`。它也逐一檢查 Apple 漸層字的每一段對舞台是否達到 3:1，因為漸層字無法由頁面截圖量測。
- `render.cjs`：與 `../illustration-renderings/` 同一支，會檢查每段文字對它背後實際畫面的對比。

```bash
python3 make.py && node render.cjs
```

## 設計決定

- **Apple 的裝置在兩種舞台上都是深色玻璃**，螢幕介面也維持深色。主視覺保留自身顏色，淺色舞台上反而更突出。
- **淺色舞台**：
  - 邊緣光改成柔和光暈。
  - 地面加一層中性接觸陰影。
  - 關鍵字漸層加深，每一段對舞台都要 ≥ 3:1。
- **深色石板**：
  - 焦點色塊提亮，色塊上的字改用深墨。
  - 中性灰兩階比底色亮一到兩階。
  - 警示色改成珊瑚紅。
- **無彩色焦點**（淺色的墨黑、深色的紙白）：總結內文用說明灰，關鍵字用墨色或紙白，仍然只靠顏色強調。

## 驗證

十二張的文字對比全數通過。

- 最低一張是深色石板綠，4.55:1。
- 漸層字最低是淺色暖橘的第一段，3.2:1，只用在 46 px 以上的字。
