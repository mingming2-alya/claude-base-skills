# 風格規格：插畫場景（共用規則與首批畫風）

_2026-11-19，首批三款之一。意象圖：`outputs/style-moodboard-v5/img/01a`、`01b`、`01c`。**畫風清單待定**，見最後一節。_

## 身分

用摸得到的物件，把抽象的事講成故事；畫風可以整套切換。

- **適合**：知識分享、新人引導、內部宣導、科普。霓虹畫風另外適合夜間活動。
- **調性**：溫暖、親切、好懂。
- **由來**：使用者的簡報《AI 的第三次搬家》是最強的參考。使用者決定把紙黏土、手繪與霓虹併成一款，畫風可以切換。

## 共用規則（所有畫風都遵守）

1. **物件說故事**：每個物件都對應這頁的內容，例如新人報到就畫識別證、筆電、咖啡杯、便利貼。不放隨機裝飾。
2. **物件貼邊、中央留給文字**：物件放在畫面外圈，可以被邊緣切掉；文字區保持乾淨。
3. **同一個光源**：所有物件的亮面與陰影方向一致，預設光從左上來。
4. **同一個色調**：物件的明度與彩度落在同一個範圍，例如都是柔和的粉彩。主色取底色的色相；輔助色可以換色相，但不跳出這個色調。
5. **換畫風時文字與版面不動**：只換圖像層、底紋與該畫風的招牌框飾。
6. **一份簡報只用一種畫風。**

## 四層

| 層 | 規則 |
|---|---|
| 背景 | 依畫風：黏土是柔和漸層加左右漫射光；手繪是紙色；霓虹是暗色磚牆加招牌照出的色光 |
| 圖像 | 依畫風畫物件，遵守共用規則 1–4 |
| 元素 | 圓形頭像牌、編號圓點、頁籤圓點；形狀跟著畫風，例如黏土是立體圓、手繪是線圈、霓虹是燈管圈 |
| 文字 | 主標題是這頁的題目，頁面上最大的字。總結放在主標題下方的內文，關鍵字用強調色。條列是「粗體名稱＋一行說明」 |

## 用色規則

色相依簡報主題整組換；光線方向、文字墨色、物件的明度與彩度範圍固定。

| 角色 | 範圍（黏土與手繪） | 換不換 |
|---|---|---|
| 底色 | 主題色相 H，L 0.90–0.95，C 0.02–0.05 | **依主題推薦** |
| 物件主色 | 色相在 H ± 30° 之內，L 0.65–0.90，C 0.06–0.13；佔物件面積一半以上 | 跟著底色 |
| 物件輔助色 | 一到三色，色相不限，L 0.65–0.90，C 0.04–0.13 | **依主題推薦** |
| 亮面（紙張、杯口、高光） | L 0.95–0.97，C ≤ 0.03 | 固定 |
| 強調色（關鍵字） | L 0.45–0.58，C 0.12–0.16；用 H 的深色或對比色；只給 24 px 以上的字（對底色 ≥ 3:1） | **依主題推薦** |
| 文字墨色 | L 0.25–0.34，C ≤ 0.02，偏暖 | 固定 |
| 次要文字 | L 0.50–0.55，C ≤ 0.03；只給 24 px 以上的字 | 固定 |

意象圖的實際用色：黏土的底色 #F5E1D6（L 0.92，H 51），物件主色是蜜桃與陶土，輔助色是鼠尾草綠與奶油黃；手繪多一個天空藍。強調色 #B4512F 對底色 4.0:1。

霓虹畫風另訂：

| 角色 | 範圍 |
|---|---|
| 底色 | 暗色，L 0.14–0.20，C ≤ 0.03，不用純黑 |
| 燈管 | 二到四色，L 0.70–0.90，C ≥ 0.13，不以紫色為主；每根燈管配白色亮芯 |
| 文字 | 白字 L ≥ 0.95；次要文字 L 0.72–0.78 |

示範配色見 `outputs/color-flex-demo/`：蜜桃、鼠尾草、天青。三組都是整頁一起旋轉色相做出來的。

## 鐵律（可檢查）

1. 主標題是頁面上最大的字；總結只出現在內文。全風格共通。
2. 每個物件都對應內容。
3. 文字區沒有物件。
4. 所有物件的光影方向一致。
5. 文字對比：24 px 以上 3:1，其餘 4.5:1。

## 禁忌

- 和內容無關的裝飾物件。
- 物件壓到文字。
- 同一份簡報混用兩種畫風。
- 寫實照片與插畫混用。
- 卡通角色的既有智慧財產，例如知名角色。

| 密集數據 | 弱項：建議換顧問報告 |

初步評估（2026-11-17）：

- **版權沒有問題**：梵谷、孟克、浮世繪、古埃及與瑪雅、岩畫都已是公共領域，模仿畫風可以。復古卡通與像素不能用特定角色。
- **每種畫風要有自己的框飾**：除了換插圖，還要有自己的底紋、配色與一個招牌框飾，避免「只換皮」。例如浮世繪的題簽、埃及壁畫的橫向分欄、像素的對話框。
- **用視覺語言命名，不用單幅名畫命名**：例如「梵谷筆觸」「表現主義線條」，避免每頁都像在仿同一幅畫。
- **程式畫得好**：像素、皮影、岩畫、拓片、素描、兒童蠟筆。
- **程式畫不出水準**：浮世繪、梵谷筆觸、埃及與瑪雅人物、復古卡通角色，可能要生圖。
