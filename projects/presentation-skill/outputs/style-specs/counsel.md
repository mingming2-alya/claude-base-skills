# 風格規格：顧問報告

_2026-11-19，首批三款之一。意象圖：`outputs/style-moodboard-v5/img/06-counsel.jpg`；淺深兩種底、各三組配色見 `outputs/color-modes/sheet.jpg`。_

## 身分

讓數據和證據自己說話：色塊就是圖表，數字放到最大。

- **適合**：策略提案、決策會議、高階報告、專案評估。
- **調性**：大膽、現代、有說服力。
- **由來**：使用者兩次否決「淺紙＋海軍藍＋襯線」的傳統顧問樣式。從三個方向裡選了色塊策略，並保留巨大數字，補充「數據與證據說話最佳的呈現方式」。

## 四層

| 層 | 規則 |
|---|---|
| 背景 | 淺色紙或深色石板兩種（見用色規則），沒有紋理 |
| 圖像 | 圖表本身就是圖像。色塊的高度或長度就是數值，基準線、期限線、目標線用虛線橫切。超出目標的部分打斜線，並用實心小牌標出差距。不用照片與裝飾插圖 |
| 元素 | 區段起點用 2 px 墨線，列與列之間用 1 px 分隔線，另有實心差距牌與虛線基準。零圓角、零陰影、零漸層 |
| 文字 | 主標題只寫題目，是頁面最大的字。總結放在主標題下方的內文，關鍵字用焦點色。佐證寫成「一個大數字＋一句說明」。每頁都有資料來源 |

## 字體與字級

| 用途 | 字體 | 字級 |
|---|---|---|
| 主標題 | Noto Sans TC 900 | 80–90 px |
| 總結（內文） | Noto Sans TC 500，關鍵字 900 | 30–34 px |
| 圖表數字 | Archivo 900 | 120–180 px |
| 佐證數字 | Archivo 900，單位用 Noto Sans TC 900 | 64–80 px |

## 用色規則

底色有淺、深兩種（2026-11-19 使用者決定）。兩種都依主題推薦三組配色。

**怎麼選**：

- 淺色紙：一般會議、會被列印或傳閱的報告。
- 深色石板：暗場、大螢幕、董事會或投資人簡報。

### 淺色紙

| 角色 | 範圍 | 換不換 |
|---|---|---|
| 紙 | L 0.94–0.96，C ≤ 0.012，偏暖 | 固定 |
| 墨 | L 0.17–0.22，C ≤ 0.01 | 固定 |
| 說明灰 | L 0.38–0.50，C ≤ 0.02；對紙色 ≥ 4.5:1 | 固定 |
| 中性灰兩階 | L 0.78–0.84，C ≤ 0.02；給所有非焦點的資料 | 固定 |
| 焦點色 | L 0.25–0.52，能承載淺色字（≥ 4.5:1）。彩色時 C 0.08–0.19，也可以用接近墨色的無彩色（C ≤ 0.02）。只給建議方案、主角資料與關鍵字；當文字時可再壓暗一階 | **依主題推薦** |
| 警示色 | 紅系，L 0.48–0.55，C 0.14–0.18；給落後、超出、風險。和彩色焦點色的色相差 ≥ 60°；若焦點色本身是紅系，警示色改用深琥珀 | 固定（必要時避讓） |

三組示範配色都落在範圍內（見 `outputs/color-modes/`）：綠 #0D6B4F（L 0.47）、藍 #1F4FBF（L 0.47）、墨黑 #1F2328（L 0.25，無彩色）。

焦點色用無彩色時，總結內文改用說明灰、關鍵字用墨色，仍然只靠顏色強調（2026-11-19 調整墨黑配色）。

### 深色石板（2026-11-19 新增）

| 角色 | 範圍 | 換不換 |
|---|---|---|

| 主文字 | L 0.92–0.95 | 固定 |
| 說明灰 | L 0.66–0.80，C ≤ 0.02；對底色 ≥ 4.5:1 | 固定 |
| 中性灰兩階 | L 0.30–0.36，比底亮一到兩階；給非焦點的資料，上面的字用主文字色 | 固定 |

## 版面語言

- 左文右圖約 40:60。左欄是主標題、總結與佐證列；右欄是一張主圖表，貼底出血。
- 一頁一張主圖表。圖表上的數字直接寫在資料旁，不用圖例。
- 比較三個以上的方案時，依數值排序，主角放第一個。

## 鐵律（可檢查）

1. 主標題是頁面上最大的字；總結只出現在內文。全風格共通。
2. 每個主張都有一個數字或證據撐著；佐證列每列都有數字。
3. 只有一個焦點色，其餘資料一律中性灰；警示色只標問題。
4. 每頁都有資料來源。
5. 圖表直接標註，不用圖例。
6. 文字對比：24 px 以上 3:1，其餘 4.5:1。

## 禁忌

- 第二個焦點色。
- 圓角卡片、陰影、漸層、3D 圖表。
- 超過三片的圓餅圖。
- 圖例。
- 裝飾插圖。
- 把總結當標題。
- 沒有出處的數字。

## 內容結構的適配

| 結構 | 做法 |
|---|---|
| 單一大數字、多個數字 | 強項：巨大數字；多個數字時只有主角用焦點色 |
| 主張配數字 | 強項：左欄總結＋右欄色塊 |
| 前後對比、分階段對照 | 強項：兩組色塊並排，差距用實心牌標出 |
| 圖表類（長條、比例、趨勢） | 強項：色塊長條、單色比例條、一條焦點線配灰色脈絡線 |
| 表格 | 改成帳冊列：一列一個項目，數值靠右；重點列用焦點色 |
| 步驟、時間軸 | 色塊橫排，長度代表時間；期限用虛線 |
| 引言 | 弱項：改成「一句引言＋一個佐證數字」 |
| 圖文 | 弱項：照片少用，必要時用灰階小圖 |
