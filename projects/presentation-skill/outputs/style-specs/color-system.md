# 用色系統：鎖規則，依主題推薦三組配色

_2026-11-19。依使用者決定（`inputs/presentation-principles.md` 第 17–19 條）。_

## 原則

1. **每款風格只定用色規則，不定死色碼。** 規則寫清楚三件事：有哪些顏色角色、每個角色的明度與彩度範圍、哪些角色固定不動。
2. **做簡報時才決定色碼。** 在視覺關卡，依這份簡報的主題推薦三組配色，都要符合所選風格的規則，由使用者選一組。
3. **不放公司品牌色。**
4. **底色明暗也不定死**（2026-11-19 使用者決定）。**每款風格都要有淺、深兩種底**：Apple 發表的深色舞台、顧問報告的淺色紙都保留，各自再補另一種明暗，其他風格寫規格時一併定兩套。做簡報時先依場合決定明暗，再在這個明暗下推薦三組配色；使用者也可以要求看另一種明暗。
5. **全風格共通的禁忌**：
   - 不用紫色主調的漸層。紫色指 OKLCH 色相 280–335，從靛紫到洋紅；常見的「AI 紫漸層」（#667EEA → #764BA2）就落在這一段。
   - 底色不用純白（#FFFFFF）或純黑（#000000），改用接近的白或黑。
   - 重點只用顏色標示，不畫底線。

範圍用 OKLCH 表示：L 是明度（0–1），C 是彩度，H 是色相角度。人眼對 OKLCH 的感受比 HSL 一致，同一個 L 在不同色相下看起來一樣亮。L 不是線性亮度：近黑的 #0B0B0D 約 0.15，紙色 #F1EFEA 約 0.95。

各規格的範圍都用意象圖與 `outputs/color-modes/` 的實際色碼核對過（2026-11-19）。

## 三組配色怎麼推薦

**零、先決定明暗。** 暗場、大螢幕、開場與發表偏深色；明亮的會議室、白天的場合、會被列印或轉成 PDF 傳閱的簡報偏淺色。brief 沒有線索時，用該風格的原生明暗。

**一、從 brief 找主題色相。** 讀 brief 的主題、場合、聽眾與想留下的情緒，選一到兩個主題色相。起始對照表：

| 主題 | 色相方向 |
|---|---|
| AI、軟體、數位工具 | 藍、青 |
| 永續、環境、健康 | 綠、青綠 |
| 財務、投資、年度成果 | 深藍、金 |
| 慶典、尾牙、週年 | 紅、金 |
| 人資、關懷、新人 | 蜜桃、鼠尾草綠 |
| 教育、學習 | 暖黃、綠 |
| 文化、歷史 | 朱、赭、墨 |
| 食品、餐飲 | 暖橘、番茄紅 |
| 醫療、照護 | 青、淡藍 |
| 製造、工程 | 鋼藍、橘 |

對照表只是起點。brief 有更具體的線索時以線索為準，例如產品本身的顏色、活動的季節。

**二、套進風格規則，產生三組。**

- **貼題**：直接用主題色相。
- **沉穩**：同色相降低彩度、往鄰近色相移 30° 左右，或在風格允許時改用無彩色。
- **外卡**：主題色相的對比色或意外但說得通的色相，仍要符合規則與禁忌。

**三、自動檢查。** 不通過就調整或換掉該組：

- 文字對比：24 px 以上 3:1，其餘 4.5:1。
- 焦點色與警示色的色相差 ≥ 60°；焦點色是無彩色時免檢。
- 沒有紫色主調的漸層：色相 280–335 不當主色。
- 三組彼此不能太像：各組的焦點色（Apple 用主漸層的中段色）兩兩 ΔE（CIELAB）≥ 15。
- 每個角色都落在風格規則的範圍內。

**四、呈現。** 用同一頁樣張套三組配色並排，做法同 `outputs/color-modes/sheet.jpg`。每組附一句理由，例如「藍：對應 AI 工具；冷靜可信」。使用者選一組，或指定調整。

## 各風格的角色

| 風格 | 明暗 | 依主題換色的角色 | 固定不動的角色 |
|---|---|---|---|
| Apple 發表 | 深色舞台、淺色舞台 | 主漸層（關鍵字、勾選）、邊緣光、地面光 | 舞台色、主文字、說明灰；裝置維持深色玻璃 |
| 顧問報告 | 淺色紙、深色石板 | 一個焦點色 | 底色、主文字、說明灰、兩階中性灰、警示色 |
| 插畫場景 | 每種畫風都要淺、深兩種底（目前多數只有淺底，霓虹與梵谷筆觸只有深底；待補） | 底色與物件主色的色相、輔助色、強調色 | 光線方向、文字墨色、物件的明度與彩度範圍 |

兩種明暗、各三組配色的示範見 `outputs/color-modes/sheet.jpg`。

細節見各風格規格。
