# 風格規格（首批）

2026-11-19 初版。使用者選定的首批三款，加上一份共用的用色系統。

| 檔案 | 內容 | 意象圖 | 狀態 |
|---|---|---|---|
| `color-system.md` | 共用：每款鎖用色規則，做簡報時依主題推薦三組配色 | `../color-flex-demo/sheet.jpg` | 完成 |
| `apple.md` | Apple 發表 | `../style-moodboard-v5/img/04-apple.jpg` | 完成 |
| `counsel.md` | 顧問報告 | `../style-moodboard-v5/img/06-counsel.jpg` | 完成 |

每份風格規格的段落依序是：

1. 身分
2. 四層：背景、圖像、元素、文字
3. 字體與字級
4. 用色規則
5. 版面語言
6. 可檢查的鐵律
7. 禁忌
8. 內容結構的適配
9. 來源

全風格共通的規則在 `../../inputs/presentation-principles.md`，例如：

- 總結不當主標題。
- 重點只用顏色標示。
- 底色不用純白或純黑。

色彩範圍用 OKLCH 表示，都用意象圖與示範配色的實際色碼核對過。
