# 風格規格：Apple 發表

_2026-11-19，首批三款之一。意象圖：`outputs/style-moodboard-v5/img/04-apple.jpg`；深淺兩種舞台、各三組配色見 `outputs/color-modes/sheet.jpg`。_

## 身分

暗場或亮場的舞台、一句話、一個發光的產品。

- **適合**：產品與工具發表、年度大會開場、主題演講、成果揭曉。
- **調性**：俐落、高級、期待。
- **不適合**：密集的數據報告、需要逐列比較的表格、長篇條列。

## 四層

| 層 | 規則 |
|---|---|
| 背景 | 舞台有深、淺兩種（見用色規則），都不用純黑或純白。沒有紋理與格線。光只從兩處來：主視覺本身的邊緣光，以及畫面底部的地面光。光不墊在文字後面 |
| 圖像 | 一頁一個主視覺，例如產品、裝置、介面畫面、抽象光體。置中或偏下，可以被畫面底邊切掉，像站在舞台上。邊緣光用配色裡的漸層 |
| 元素 | 白色 22% 的細線標註（1.5 px）、功能說明（標題＋兩行說明）、便當格功能卡（近黑灰卡、圓角 28 px、無陰影）、勾選與進度列。不用粗框、硬陰影或彩色卡片 |
| 文字 | 置中為主。主標題是產品名或這頁的題目，頁面上最大的字。總結放在主標題下方的內文，關鍵字用漸層色。說明文字用灰色 |

## 字體與字級

| 用途 | 字體 | 字級 |
|---|---|---|
| 主標題 | Noto Sans TC 700；數字與英文用 Geist 700 | 110–140 px，字距 −0.01em |
| 總結（內文） | Noto Sans TC 500，關鍵字 700 | 40–48 px |
| 標註標題 | Noto Sans TC 700 | 30–34 px |
| 說明 | Noto Sans TC 400 | 22–24 px |
| 頁籤 | Noto Sans TC 500 | 21 px |

## 用色規則

舞台有深、淺兩種（2026-11-19 使用者決定不定死深色）。兩種都依主題推薦三組配色。

**怎麼選**：

- 深色舞台：暗場、大螢幕、發表會開場。
- 淺色舞台：明亮的會議室、白天的場合，以及會被列印或轉成 PDF 傳閱的簡報。

主視覺保留自身顏色：裝置在兩種舞台上都是深色玻璃，螢幕上的介面也維持深色，所以在淺色舞台上更突出。

### 深色舞台

| 角色 | 範圍 | 換不換 |
|---|---|---|
| 舞台黑 | L 0.13–0.18，C ≤ 0.01（約 #0A0A0B 到 #121214） | 固定 |
| 主文字白 | L ≥ 0.95，C ≤ 0.01 | 固定 |
| 說明灰 | L 0.62–0.70，C ≤ 0.01 | 固定 |
| 主漸層 | 三色由亮到深：起點 L 0.80–0.92，終點 L 0.58–0.72；C 0.09–0.23；三個色相相鄰，總跨度 ≤ 90°。用在關鍵字、勾選與進度 | **依主題推薦** |
| 邊緣光 | 四色，涵蓋主漸層的色相，總跨度 ≤ 180°；L 0.68–0.95，C 0.07–0.20。只用在主視覺的外框光 | 跟著主漸層 |
| 地面光 | 主漸層的中段色，透明度 0.15–0.30，模糊後放在畫面底部 | 跟著主漸層 |

漸層色當文字時只用在 24 px 以上，每一段對舞台黑都要 ≥ 3:1。三組示範配色（暖橘、冰藍、翠綠，見 `outputs/color-flex-demo/`）都落在上面的範圍內；最深的一段是冰藍的 #2F6BFF，對舞台黑 4.4:1。

意象圖原本用純黑 #000 當底，違反「底色不用純黑」；2026-11-19 改成 #0B0B0D，並重新產生意象圖與示範配色。

### 淺色舞台（2026-11-19 新增）

| 角色 | 範圍 | 換不換 |
|---|---|---|
| 舞台 | L 0.92–0.98，C ≤ 0.01；上亮下略暗的漸層，例如 #F7F7F9 → #F2F2F5 → #E6E6EB；不用純白 | 固定 |
| 主文字 | L 0.20–0.26，C ≤ 0.01 | 固定 |
| 說明灰 | L 0.46–0.50，C ≤ 0.01；在舞台最暗處也要 ≥ 4.5:1 | 固定 |
| 主漸層 | 三色由亮到深：起點 L 0.56–0.66，終點 L 0.48–0.55；C 0.08–0.22；每一段對舞台 ≥ 3:1 | **依主題推薦** |
| 邊緣光 | 四色，做成柔和光暈（透明度 0.4–0.75），可以比深色版更飽和 | 跟著主漸層 |
| 地面 | 一層中性接觸陰影（透明度 0.15–0.2），加極淡的主漸層中段色（≤ 0.08） | 跟著主漸層 |

淺色舞台的三組示範配色：

| 配色 | 漸層 | 最淺一段對舞台 |
|---|---|---|
| 暖橘 | #E8590C → #E03131 → #C2255C | 3.2:1 |
| 冰藍 | #0C8599 → #1C7ED6 → #1864AB | 3.8:1 |
| 翠綠 | #5C940D → #2B8A3E → #0B7285 | 3.3:1 |

漸層只用在 46 px 以上的字，3:1 足夠。

## 版面語言

- 置中、一頁一個重點、大片暗部留白。
- 主標題在上，主視覺在下並出血。
- 標註左右對稱，用細線指向主視覺。
- 功能總覽用便當格，承接上一輪移出的便當格。

## 鐵律（可檢查）

1. 主標題是頁面上最大的字；總結只出現在內文。全風格共通。
2. 背景只有舞台色與最多兩處光源；光不在文字後面。
3. 一頁一個主視覺。
4. 漸層只用在關鍵字、邊緣光與地面光，不鋪大面積底色。
5. 文字對比：24 px 以上 3:1，其餘 4.5:1。

## 禁忌

- 紫色主調漸層。
- 霓虹格線與科幻介面。
- Apple 的商標、字體或產品圖。只學設計語言。
- 一頁多個主視覺。
- 彩色的大面積底色。舞台只用近黑或淺灰。
- 有陰影的卡片堆疊。
- 文字壓在光暈上。

## 內容結構的適配

| 結構 | 做法 |
|---|---|
| 封面、章節、結尾 | 強項：產品名或章名置中，主視覺在下 |
| 單一大數字 | 強項：巨大數字＋一行說明，數字用漸層 |
| 功能、條列 | 便當格功能卡，或左右標註 |
| 前後對比 | 左右兩個裝置畫面，舊的調暗 |
| 圖表 | 極簡：一條發光的長條或線，只標兩三個關鍵值，不畫格線 |
| 表格 | 弱項：改成便當格或精簡列，最多五列 |
| 長時間軸 | 弱項：改成一條細線加四五個節點 |
| 單句震撼頁 | 允許整頁只有一句（使用者原則中的情緒轉折頁），不放主視覺 |
