## 共用與各自

**全部共用**：文字層（`src/base.css`）。字體、字級與版面都一樣：

- 頁籤
- 主標題（Chiron GoRound TC 76 px）
- 總結內文（34 px，關鍵字用強調色）
- 條列（徽章、名稱、說明）

**每種畫風各自**：畫法、底紋、配色、一個招牌框飾。條列的徽章也跟著畫風換，例如像素方塊、膠片倒數圈、王名圈、點槓數字。

## 驗證

`node render.cjs` 會產生每張 JPG，並檢查四件事：

- 文字框不超出畫面、沒有溢出。
- 字體都載入成功。
- 頁面腳本沒有錯誤。
- **每段文字對它背後實際畫出來的東西**都符合 WCAG 對比：24 px 以上 3:1，其餘 4.5:1。

不帶參數時，另外重建 `overview.jpg`。

做法是先記下每段文字的顏色與位置，再把文字藏起來截圖，取每段字形範圍內背景亮度的第 10 與第 90 百分位，用較差的一邊算對比。

十二張全數通過。最低的是：

| 畫風 | 最低對比 | 位置 |
|---|---|---|
| 梵谷 | 3.29 | 24 px 頁籤，在筆觸夜空上 |
| 吶喊 | 3.51 | 頁籤，在硬紙板上 |
| 皮影戲 | 3.91 | 頁籤，在布幕暗角 |

**修掉的錯**：

- **兒童手繪整張沒畫出來**：全域變數取名 `top`，和瀏覽器內建的 `window.top` 衝突，整段腳本停擺。之後檢查腳本也會回報這類錯誤。
- **復古卡通的倒數數字壓在十字線上**：數字和十字線同色，看不清楚。數字後面補了底圓。
- **拓片印章字被誤判對比不足**：檢查原本取整個行高，字型的上下留白落到紙上。改為只取字形範圍。
