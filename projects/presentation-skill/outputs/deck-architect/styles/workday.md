# Style DNA：日常工作款（`workday`）

> **一句話定位**：乾淨克制的現代便當格（Bento）工作儀表板——用雙語意色、甘特時間條、圓環進度與掃讀決策卡，取代黑白 Excel 表格，讓主管三秒看懂狀態與拍板點。
> **適合**：週進度回報、多店／多專案追蹤、部門例會同步、待決事項拍板、營運儀表板。
> **避免**：大型產品發表會、情緒震撼演講、文化藝術故事。
> **參考基準**：`assets/style-library.html`（01 號 `workday` 活體舞台，現代因果 Bento 空間分群與淺深雙底）。

## 1. 四層結構（固定本質）

| 層 | 規則 |
|---|---|
| **背景層** | 柔霧冷灰紙底（淺色）或深灰藍石板（深色），搭配極微弱的左上高光與右下色溫呼吸；**不用純白／純黑，不畫網格線** |
| **圖像層** | **視覺化進度元件就是主視覺**：雙軌甘特對比條（原訂 vs 實際＋紅斜線延遲區）、SVG 圓環完成度、整體完成度大數字＋迷你直條群、條列佇列進度條。不插無關裝飾圖 |
| **元素層** | 統一圓角 `24–26px` 卡片、1px 細邊框、極輕微層次陰影（不堆重黑影）；狀態膠囊（圓角 `999px`）；風險卡使用淡暖底＋細紅框標示；拍板區用雙欄 A/B 推薦卡 |
| **文字層** | 頂部左列膠囊分頁導航＋右列週次狀態膠囊（例 `W47`）；**主標題沉穩暗墨色＋一句話結論**（僅卡點詞染風險色）＋右側雙色狀態圖例；**嚴守原則 #26**：每張卡最多兩層資訊（核心數字／狀態＋短標籤），不塞解釋小字段落 |

## 3. 雙語意用色規則（OKLCH）

**核心紀律：最多兩個語意主色（正常綠／焦點色 ＋ 風險陶磚紅）**，絕不把藍、紫、橘、黃、綠混成彩虹儀表板。標題區維持沉穩中性色，色相留給「進度正常 vs 需要介入」的訊號。

### 淺色工作底（`mode: light`，預設）
- 畫布底：`L 0.93–0.95, C 0.008–0.015` 偏冷灰（例 `#E7ECF1`）｜卡片面：`#FCFBF9`（暖白不刺眼）｜邊框：`#D9DFE8`
- 主文字：`#161A21`｜次文字：`#3F4652`｜輔助標籤：`#58606E`（對卡片面皆 `≥ 4.5:1`）
- 正常／進度色（OK）：深森綠 `#0E6B4F`（柔和輔色 `#2E7D63`，淡底 `#E2F2EB`）；可依主題替換為同明度深海藍或靛青
- 風險／待決色（Risk）：陶磚紅 `#C03C1E`（文字專用深磚 `#A63016`，淡暖底 `#FFF5EE`，框線 `#EFC7B4`）

### 深色工作底（`mode: dark`）
- 畫布底：`#10141B`｜卡片面：`#181E27`｜邊框：`rgba(241, 239, 234, 0.12)`
- 主文字：`#F1EFEA`｜次文字：`#C2C7D0`｜輔助標籤：`#8E96A4`
- 正常／進度色（OK）：薄荷綠 `#4AD49A`（淡底 `rgba(74,212,154,0.16)`）
- 風險／待決色（Risk）：珊瑚紅 `#FF7657`（淡底 `rgba(255,118,87,0.14)`，框線 `rgba(255,118,87,0.38)`）

## 4. 版面語法與內容形狀適配

- **導航**：左上圓角分段膠囊（`nav` 內建 `data-auto-nav`，並設 `data-nav="inline"` 隱藏全域導航），右上對稱放週次／期數膠囊（如 `W47・Q4 追蹤`）。
- **主標題與圖例對齊**：左側主標題＋一行精簡結論；右側底部對齊雙色狀態圖例（例 `● 4 店按進度　● 1 店需介入`），讓頁首與下方 Bento 卡邏輯完全呼應。
- **多專案進度頁（取代黑白色表格，採左右分區單向動線、禁四散四角）**：
  - **左欄（需要介入的行動閉環，同寬垂直對齊）**：上放`唯一焦點風險甘特卡` → 垂直因果箭頭直指正下方`雙選項拍板決策卡`（A 建議／B 過渡，每項限 2 行）。
  - **右欄（按進度健康總覽群組，由總到分、由高到低）**：上放`整體完成度總覽卡（含各店迷你直條）` → 中排並列`高進度／已上線圓環卡（100% → 75%）` → 底排`接續佇列進度卡`；左右兩欄底部精準齊平。
- **大量列項（>6 個專案或正式週報長表）**：仍可沿用 `status-table` 元件並覆蓋本風格的雙語意色變數。

## 5. 動效個性（Phase B 參數）

- **性格**：`crisp`（俐落精準、零多餘彈跳，像 Linear / Raycast 儀表板一樣乾脆到位）。
- **CSS 變數**：
  ```css
  --motion-mode: crisp;
  --enter-easing: cubic-bezier(0.2, 0.9, 0.25, 1);
  --stagger-base: 45;
  --morph-ms: 720;
  ```
- **建議動態標記**：
  - 整體完成度與圓環百分比加 `data-count`（快速滾動到位）。
  - SVG 進度圓環加 `data-draw="ring"`（由 0 順時針掃至目標角度）。
  - 甘特條與佇列條加 `data-grow="x"`；迷你直條加 `data-grow="y"`。
  - 6 張 Bento 卡容器可加 `data-stagger="45"`（風險焦點卡先出，其餘快節奏收斂；**卡片內子元件不可重複加 `.rv`**）。

## 6. 鐵律與禁忌（`check.mjs` 把關）

- ✅ 標題區與卡片內容邏輯一致（標題寫「五店進度」，下方就有五店整體完成度與各店分布）；雙語意色克制；每卡最多兩層文字；所有標籤 ≥ 18px。
- ❌ 禁用彩虹多色徽章、黑白純線框 Excel 表樣式、卡片內寫超過 2 行的長段落說明、重黑投影或玻璃霓虹特效。

## 7. 專屬動態模組（`motion-workday` · 按需注入，未用到 0 KB）

- **動態個性**：**俐落精準（Crisp Snap）**——零過衝、快切穩停、強調主焦點收斂。
- **綁定原語**（用法見 `references/modules/style-motion-kits.md`）：
  - `[data-ruler-progress]`：物理阻尼刻度尺推進＋達標目標線亮燈（適合里程碑／KPI 完成度）。
  - `[data-bento-expand]`：點擊風險或決策卡滑順展開詳情，同排自動壓暗退讓（適合週報／例會現場展開追問）。
- **搭配模組**：`components`、`linked-highlight`、`compare-slider`、`visual-flair(zoomable)`。
- **禁忌動態**：禁用 `spotlight-sweep`、`depth-deck`、`colorize-wipe`、`ambient-fx`、`coverflow` 等舞台裝飾動效。
