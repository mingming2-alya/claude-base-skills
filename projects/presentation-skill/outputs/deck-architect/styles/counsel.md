# Style DNA：顧問報告（`counsel`）

> **一句話定位**：溫潤畫廊秩序 × 數據編輯美學——讓比例幾何、三階字重與精準數字自己說話。
> **適合**：高階策略提案、決策會議、年度戰術成果、專案評估、成效比較。
> **避免**：慶典活動、感性說故事、兒童與生活主題。
> **參考基準**：`assets/style-library.html`（02 號 `counsel` 活體舞台，淺色畫廊紙與深色石板雙底切換）。

## 1. 四層結構（固定本質）

| 層 | 規則 |
|---|---|
| **背景層** | 溫潤畫廊紙底（淺色，保持 ≥75% 沉靜中性紙面）或深色石板（深色），搭配次級溫白／冷岩分區底（`--bg-2`），不用純白／純黑 |
| **圖像層** | **比例圖表與因果幾何就是主視覺**。色塊高度／長度、收斂漏斗或單位矩陣直接編碼數值與因果流向；基準線／目標線用細虛線橫切；差距用實心小牌直接點出 |
| **元素層** | 區段 1.5–2px 主軸線、1px 細髮絲分隔（`--line`）、微圓角（`6–12px`）紙面卡片與極淡高度差微影（`0 2px 12px rgba(20,22,25,0.04)`），營造雜誌畫廊層次；**不堆重黑陰影、不做玻璃霓虹** |
| **文字層** | **三階字重呼吸**（拒絕全頁 `900` 粗黑壓迫）：主標題 `600–800`（可選襯線／無襯線搭配）＞ 等寬數值 `700–800` ＞ 內文與短標籤 `400–600`；每頁附資料來源 |

## 3. 用色規則（OKLCH · 支援雙語意主色分工）

**語意色紀律**：預設 **1 個主焦點色**（`--accent`，給核心結論、實績成果與主角數據）；當高密策略頁同時包含兩個正交維度（例如「戰術機制／體系投入」vs「已落地實績／閉環產出」）時，允許啟用 **第 2 個沉穩語意色**（`--accent-2`，與主焦點色相差 `≥ 45°`，搭配 `8–12%` 淡色底襯托分區），不擴張為三四種彩虹色。

### 淺色畫廊紙（`mode: light`，預設）
- 底紙：`L 0.95–0.97, C ≤ 0.012` 偏暖（例 `#F4F2EC`）｜次級紙卡：`#FCFBF8`｜墨字：`L 0.17–0.22`（`#16191E`）｜說明灰：`L 0.38–0.50`（`#434952`）
- 中性脈絡灰：`L 0.78–0.86, C ≤ 0.018`（例 `#D4CFC6` / `#E5E1D8`），保持全頁 **≥ 75%** 亮面呼吸感，避免塞入大面積死黑底塊
- 主焦點色（`--accent`）：`L 0.30–0.50, C 0.09–0.18`（例松石綠 `#0E6B4F` 或深海藍 `#1B4D89`），承載淺字 `≥ 4.5:1`
- 第二語意色（`--accent-2`，選用）：`L 0.34–0.52, C 0.07–0.15`（例暖琥珀銅 `#8F5319` 或鋼青 `#23576E`）
- 警示色：紅系 `L 0.48–0.55, C 0.14–0.18`（例 `#B5381F`）

### 深色石板（`mode: dark`）
- 石板底：`L 0.18–0.23, C ≤ 0.015`（例 `#14181F`）｜次級卡面：`#1C222C`｜主文字：`#ECEAE4`｜說明灰：`#AEB5C0`
- 主焦點色：`L 0.62–0.74, C 0.10–0.17`｜第二語意色（選用）：`L 0.64–0.76, C 0.08–0.15`｜警示色：`#FF7A5C`

## 4. 雙密度版面語法（`airy` 單核留白 × `structured` 高密畫廊秩序）

- **`airy` 單核大留白模式**（適合單一指標突破、前後差距、章節主張）：
  - 左文右圖 `38:62` 或上下極簡對照：左欄主標題＋一句錨點＋2 個大數字佐證；右欄一張貼邊比例長條、折線或單位矩陣（Unit Waffle Matrix），直接標註數值、零圖例。
- **`structured` 高密多區畫廊模式**（適合 1–2 頁講清「戰術收斂 × 分工矩陣 × 落地實證 × 閉環路線」的高階匯報）：
  - 全頁嚴控 **≤ 4 個空間分區**（`zones`），以溫白紙卡（`--bg-2`）與 `1px` 細線劃出清晰單向動線（如「左：收斂漏斗 → 中：分工與實證雙軌 → 右／底：下階段閉環」）；
  - 每張子卡嚴守 **兩層文字**（關鍵數字／短標題 ＋ ≤12 字短錨點），用 SVG 流向箭頭、比例條與矩陣取代所有解釋段落，口徑細節放進 `notes` 或 `appendix`。
- **導航**：左上對齊細字（`--nav-left: 88px; --nav-top: 40px`）或高密單頁 `nav_mode: minimal-side`。

## 5. 動效節奏（全風格統一從容慢板標配）

- **敘事觀看標配從容慢板**：讓高階主管眼睛跟得上每一筆因果推導，拒絕一閃而過的快切閃現。
- **CSS 變數**：
  ```css
  --motion-mode: spring;
  --enter-easing: cubic-bezier(0.22, 1, 0.36, 1);
  --stagger-base: 240;
  --morph-ms: 780;
  ```
- **建議動態標記**：SVG 收斂路徑／折線加 `data-draw`（`~980ms` 從容描繪）；比例條加 `data-grow="x|y"`（`~920ms`）；核心指標加 `data-count` 或 `[data-odometer]`；≥3 個依序推導區塊在 `talk`/`discuss` 下搭配 `data-step`（≤5 拍）逐拍揭曉。

## 6. 鐵律與禁忌

- ✅ 主標題字級大於副標；三階字重分明；高密頁 ≤4 個空間分區且每卡 ≤2 層字；數據具來源或備註口徑。
- ❌ 禁用全頁塞滿 `900` 粗黑字重、禁用三種以上彩虹色塊、禁用浮誇重黑陰影與 3D 立體餅圖、禁用在亮底塞大塊死黑背景壓迫版面。

## 7. 專屬動態模組（`motion-counsel` · 按需注入，未用到 0 KB）

- **動態個性**：**權威定焦（Editorial Weight）**——從容推進、柔緩落定、證據與因果優先。
- **綁定原語**（用法見 `references/modules/style-motion-kits.md`）：
  - `[data-rank-race]`：FLIP 排名攀升超車交換（適合前後季排名變化、方案評比超車）。
  - `[data-odometer]`：機械滾輪數字從容煞停（適合核心收斂倍率與年度 KPI 結論）。
  - `[data-rack-focus]`：鏡頭景深聚焦當前證據區，其餘柔和退焦（適合多區高密畫廊逐區導覽）。
- **搭配模組**：`live-controls`、`linked-highlight`、`compare-slider`、`components`。
- **禁忌動態**：禁用 `popup-fold`、`confetti-burst`、`data-tilt`。
