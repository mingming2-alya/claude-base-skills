# Style DNA：顧問報告（`counsel`）

> **一句話定位**：讓數據和證據自己說話——色塊就是圖表，數字放到最大。
> **適合**：策略提案、決策會議、高階報告、專案評估、成效比較。
> **避免**：慶典活動、感性說故事、兒童與生活主題。
> **參考基準**：`outputs/color-modes/sheet.jpg`（淺色紙與深色石板各三組配色）。

## 1. 四層結構（固定本質）

| 層 | 規則 |
|---|---|
| **背景層** | 淺色紙或深色石板（不用純白／純黑），乾淨無紋理 |
| **圖像層** | **圖表本身就是主視覺**。色塊高度／長度直接編碼數值，貼底或貼邊出血；基準線／期限線用虛線橫切；超出或落後區打斜線並配實心差距小牌。不用照片與裝飾插圖 |
| **元素層** | 區段起點 2px 強線、列間 1px 細線、實心差距牌、虛線基準線。**零圓角、零陰影、零漸層** |
| **文字層** | **主標題＝這頁題目（最大字）**；總結放主標題下方內文，關鍵字用焦點色；佐證寫成「大數字＋一句說明」；每頁附資料來源 |

| 角色 | 字體堆疊（含離線退路） | 字級 |
|---|---|---|
| 主標題（最大） | `"Noto Sans TC", var(--font-sans-fallback)` 900 | 78–92 px |
| 總結內文 | `"Noto Sans TC", var(--font-sans-fallback)` 500（關鍵字 900 焦點色） | 30–34 px |

| 佐證數字 | `"Archivo", "Noto Sans TC", var(--font-sans-fallback)` 900 | 56–76 px |
| 標籤／說明 | `"Noto Sans TC", var(--font-sans-fallback)` 500–700 | 20–25 px |

## 3. 用色規則（OKLCH）

**依主題換色**：**只有一個焦點色**（給建議方案、主角資料與總結關鍵字）。
**固定不動**：底色、主文字、說明灰、兩階中性灰（給非焦點資料）、警示色（給落後／超出／風險）。

### 淺色紙（`mode: light`，預設）
- 底紙：`L 0.94–0.96, C ≤ 0.012` 偏暖（例 `#F1EFEA`）｜墨字：`L 0.17–0.22`（`#141619`）｜說明灰：`L 0.38–0.50`（`#3F444B`）
- 中性灰兩階：`L 0.78–0.84, C ≤ 0.02`（例 `#CFCAC1` / `#BDB7AC`）
- 焦點色：`L 0.25–0.52`，彩色時 `C 0.08–0.19`（或無彩色墨黑 `C ≤ 0.02`，此時總結內文改說明灰、關鍵字用墨黑），能承載淺色字 `≥ 4.5:1`
- 警示色：紅系 `L 0.48–0.55, C 0.14–0.18`（例 `#B5381F`）；與彩色焦點色相差 `≥ 60°`（焦點偏紅時改深琥珀）

### 深色石板（`mode: dark`）
- 石板底：`L 0.18–0.24, C ≤ 0.015` 偏冷（例 `#15181D`）｜主文字：`L 0.92–0.95`（`#ECEAE4`）｜說明灰：`L 0.66–0.80`（`#B3B8C0`）
- 中性灰兩階：`L 0.30–0.36`（例 `#363C45` / `#2B3038`），上載主文字色
- 焦點色：色塊 `L 0.60–0.70, C 0.10–0.18`（上載深墨字 `≥ 4.5:1`）；焦點文字提亮至 `L 0.74–0.80`；或無彩色紙白 `L ≥ 0.90`（內文改說明灰）
- 警示色：珊瑚紅 `L 0.70–0.75, C 0.15–0.18`（例 `#FF7A5C`）；斜線底用暗紅 `L 0.28–0.32`

## 4. 版面語法與內容形狀適配

- **導航**：左上對齊無框細字（`--nav-left: 88px; --nav-top: 40px`），現行章節加粗墨色。
- **招牌構圖（左文右圖 40:60）**：左欄＝主標題＋總結＋2–3 條「大數字＋說明」佐證列；右欄＝一張貼底出血的主圖表，直接標註數值、不用圖例。
- **方案比較／排序**：依數值或推薦序排列，主角排第一且獨享焦點色，其餘一律中性灰。
- **前後對比／逐段對照（`lanes`）**：兩組色塊並列或逐欄對照，差距用實心小牌直接點出。
- **圖表類**：色塊長條（垂直／水平）、單色比例橫條（避免超過 3 片的圓餅圖）、一條焦點折線配灰色脈絡線。
- **表格／週報**：帳冊式橫列（無縱線、數值靠右、重點列用焦點色）；若是主管例會追蹤多店／多專案進度，優先考慮 `workday` 現代 Bento 儀表板（或長表沿用 `status-table` 元件）。
- **數據故事化主視覺**：遇「數量減半／比例縮減」議題時，優先用**單位矩陣（Unit Waffle Matrix，如 24 盤 → 9 盤）**或真實比例色塊讓觀眾一眼感受量體，佐證卡嚴守兩層文字（大數字＋6 字內短標），口頭解釋放進 `notes`。

## 5. 動效個性（Phase B 參數）

- **性格**：`crisp`（俐落精準、零多餘彈跳，像財經簡報一樣乾脆到位）。
- **CSS 變數**：
  ```css
  --motion-mode: crisp;
  --enter-easing: cubic-bezier(0.16, 1, 0.3, 1);
  --stagger-base: 35;
  --morph-ms: 740;
  ```
- **建議動態標記**：佐證大數字加 `data-count`；色塊長條加 `data-grow="x|y"`；單位矩陣外層加 `data-stagger="24"` 呈現漸進點亮；跨頁核心比率加 `data-morph`。

## 6. 鐵律與禁忌（`check.mjs` 把關）

- ✅ 主標題永遠大於總結；每個主張有數字或證據；每頁只有一個焦點色；每頁有資料來源；不用圖例；`delivery: talk` 下每個佐證格限兩層文字（不塞解釋小字）。
- ❌ 禁用第二個焦點色、裝飾性圓角浮誇特效、陰影、漸層、3D 圖表、無關裝飾插圖、無出處數字。

## 7. 專屬動態模組（`motion-counsel` · 按需注入，未用到 0 KB）

- **動態個性**：**權威定焦（Editorial Weight）**——沉穩加速、精準煞停、數據與結論優先。
- **綁定原語**（用法見 `references/modules/style-motion-kits.md`）：
  - `[data-rank-race]`：FLIP 排名攀升超車交換（適合前後季排名變化、方案評比超車）。
  - `[data-odometer]`：機械滾輪數字逐位精準煞停（適合核心 KPI 結論與成本節省）。
  - `[data-rack-focus]`：鏡頭景深聚焦某張證據卡，其餘柔和退焦（適合多論點逐一檢視）。
- **搭配模組**：`live-controls`、`linked-highlight`、`compare-slider`、`components`。
- **禁忌動態**：禁用 `popup-fold`、`confetti-burst`、`data-tilt`。
