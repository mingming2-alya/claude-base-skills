# Style DNA：Apple 發表（`apple`）

> **一句話定位**：暗場或亮場的極簡舞台、一句重點、一個發光的主視覺。
> **適合**：產品與工具發表、大會開場、主題演講、功能總覽、成果揭曉。
> **避免**：密集多欄報表、長篇逐列表格、多專案週進度表。
> **參考基準**：`assets/style-library.html`（03 號 `apple` 活體舞台，深色／淺色舞台雙底切換）。

## 1. 四層結構（固定本質）

| 層 | 規則 |
|---|---|
| **背景層** | 深或淺舞台（不用純黑／純白），無紋理無格線。光源限兩處：主視覺邊緣光＋底部地面光；**光絕不墊在文字後面** |
| **圖像層** | **一頁一個主視覺**（產品、裝置、介面、抽象光體），置中偏下並可自然出血至底邊。裝置在淺、深舞台都維持深色玻璃 |
| **元素層** | 1.5px 細線標註指向主視覺、左右對稱功能說明（標題＋最多兩行）、便當格功能卡（圓角 28px、無重陰影）、極簡勾選／進度條 |
| **文字層** | 置中為主。**主標題＝題目或產品名（頁面上最大的字）**；總結放主標題下方內文，關鍵字用漸層色；說明字用灰 |

## 2. 字體與字級（1920×1080 畫布）

`@fonts family=Noto+Sans+TC:wght@400;500;700;900&family=Geist:wght@600;700`

| 角色 | 字體堆疊（含離線退路） | 字級 |
|---|---|---|
| 主標題（最大） | `"Geist", "Noto Sans TC", var(--font-sans-fallback)` 700–900 | 104–136 px，字距 −0.015em |
| 總結內文 | `"Noto Sans TC", var(--font-sans-fallback)` 500（關鍵字 700 漸層） | 40–46 px |
| 標註標題／便當卡標 | `"Noto Sans TC", var(--font-sans-fallback)` 700 | 28–34 px |
| 說明／頁籤 | `"Noto Sans TC", var(--font-sans-fallback)` 400–500 | 21–24 px |

## 3. 用色規則（OKLCH）

**依主題換色**：主漸層（三色相鄰、跨度 ≤ 90°）、邊緣光（四色、跨度 ≤ 180°）、地面光。
**固定不動**：舞台色、主文字、說明灰、深色玻璃裝置。

### 深色舞台（`mode: dark`，預設）
- 舞台：`L 0.13–0.18, C ≤ 0.01`（例 `#0B0B0D`）
- 主文字：`L ≥ 0.95`（`#F5F5F7`）｜說明灰：`L 0.62–0.70`（`#9A9AA0`）｜細線：`rgba(255,255,255,.22)`
- 主漸層：起點 `L 0.80–0.92` → 終點 `L 0.58–0.72`，`C 0.09–0.23`（每段對舞台 `≥ 3:1`）
- 邊緣光：四色 `L 0.68–0.95, C 0.07–0.20`｜地面光：中段色透明度 `0.15–0.28`

### 淺色舞台（`mode: light`）
- 舞台：`L 0.92–0.98, C ≤ 0.01` 上亮下微暗漸層（例 `#F7F7F9 → #F2F2F5 → #E6E6EB`）
- 主文字：`L 0.20–0.26`（`#1D1D1F`）｜說明灰：`L 0.46–0.50`（`#5E5E63`，對最暗舞台 `≥ 4.5:1`）｜細線：`rgba(29,29,31,.20)`
- 主漸層：**必須加深**，起點 `L 0.56–0.66` → 終點 `L 0.48–0.55`，`C 0.08–0.22`（每段對舞台 `≥ 3:1`，僅用於 ≥40px 大字）
- 邊緣光：柔和光暈透明度 `0.40–0.70`｜地面：中性接觸陰影 `0.15–0.20`＋極淡主題色 `≤ 0.08`

## 4. 版面語法與內容形狀適配

- **導航**：頂部置中極簡橫排（`--nav-justify: center; --nav-top: 38px`），不畫多餘底線或框線。
- **封面／揭曉**：大產品名或題目置中偏上，發光主視覺從底部升起並出血。
- **單一大數字**：巨型漸層數字置中（180–260px）＋下方一行精簡說明。
- **功能總覽／條列**：2×2 或不對稱 3–5 格**便當格（Bento Grid）**，或主視覺左右對稱細線標註。
- **前後對比**：左右兩台裝置／介面並排，舊版壓暗、新版發光。
- **圖表**：極簡單條發光長條或光線趨勢，直接標 2–3 個關鍵值，無格線無圖例。
- **震撼頁**：允許全頁淨空只留一句白／墨大字與漸層關鍵字，不放裝置。

## 5. 動效個性（Phase B 參數）

- **性格**：`spring`（Apple Keynote 可打斷解析彈簧，臨界阻尼零過度回彈，靈感自 MIT `emilkowalski/skills` apple-design）。由暗漸亮，標題先落位、主視覺隨後浮現，裝置內折線與長條以 `data-draw`／`data-grow` 依序就位。
- **CSS 變數**：
  ```css
  --motion-mode: spring;
  --spring-response: 0.56;
  --spring-bounce: 0;
  --stagger-base: 55;
  --morph-ms: 780;
  ```
- **建議動態標記**：跨頁核心指標加 `data-morph`；裝置內趨勢線加 `data-draw`；分批長條加 `data-grow="x"`；可選擇於背景掛 `data-fx="soft-aurora"` 微光呼吸。

## 6. 鐵律與禁忌（`check.mjs` 把關）

- ✅ 主標題必須大於總結；左右標註嚴守**兩層文字**（大數字／短詞＋短標籤，講者解釋進 `notes`）；漸層字每段色標對舞台 `≥ 3:1`；一般字 `≥ 4.5:1`。
- ❌ 禁用紫色主調漸層（H 280–335）、科幻霓虹格線、標註區塞滿 3 層說明段落、一頁多個主視覺、彩色滿版底、重陰影堆疊卡片、Apple 商標或原產品圖。

## 7. 專屬動態模組（`motion-apple` · 按需注入，未用到 0 KB）

- **動態個性**：**電影舞台（Cinema Spring）**——大張力預備、微彈簧回正、光影主從跟隨。
- **綁定原語**（用法見 `references/modules/style-motion-kits.md`）：
  - `[data-split-mask]`：文字裁切遮罩逐行拉起（適合章節宣言與震撼主標題）。
  - `[data-spotlight-sweep]`：擺動或滑鼠追隨聚光燈掃字顯影（適合暗底揭曉核心主張）。
  - `[data-depth-deck]`：3D 景深疊卡甩牌翻面（適合逐項揭曉亮點或方案演進）。
  - `[data-colorize-wipe]`：黑白柔焦→彩色光幕掃入（適合新舊世代、前後升級對照）。
- **搭配模組**：`media`、`flow-carousel`、`coverflow`、`ambient-fx`、`compare-slider`。
- **禁忌動態**：禁用密集 `status-table` 與 `chat-replay`。
