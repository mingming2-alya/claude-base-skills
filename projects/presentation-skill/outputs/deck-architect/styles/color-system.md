# 用色系統：鎖規則、不鎖色碼（Style DNA 共用）

## 四條鐵律

1. **只鎖用色規則，不定死色碼**：每款風格只規定顏色角色、OKLCH 範圍與固定不動的部分；做簡報時依主題動態生成三組配色讓使用者選一組。
2. **不放公司品牌色**：配色只服務這份簡報的主題與情緒。
3. **全部風格支援淺、深兩種底**：先依場合決定明暗，再在這個明暗下推薦三組配色（使用者也可要求看另一種明暗）。
   - **淺色底**：明亮會議室、白天場合、會列印或轉 PDF 傳閱。
   - **深色底**：暗場、大螢幕、大會開場、發表會。
   - **變暗不等於夜晚**：深色版只換光線或材質深色款；月亮星星只隨內容出現。
4. **全風格禁忌**：
   - 禁用純白（`#FFFFFF`）與純黑（`#000000`）當底色。
   - 禁用紫色主調（OKLCH 色相 `H 280–335` 且 `C ≥ 0.04`，含常見 AI 紫漸層）。
   - 重點只用顏色標示，不畫底線、不用斜體。

## 依主題推薦三組配色的步驟

1. **定明暗**：讀 `brief.md` 的場合決定 `light` 或 `dark`；無線索時用該風格的 `default_mode`。
2. **找主題色相**（起始參考；若 brief 有更具體的產品／季節線索，以線索為準）：

| 主題 | 色相方向 |
|---|---|
| AI、軟體、數位工具 | 藍、青（H 210–255） |
| 永續、環境、健康 | 綠、青綠（H 145–185） |
| 財務、投資、年度成果 | 深藍、金（H 250 / H 80） |
| 慶典、尾牙、週年 | 紅、金（H 25 / H 80） |
| 人資、關懷、新人 | 蜜桃、鼠尾草綠（H 45 / H 145） |
| 教育、學習、分享 | 暖黃、綠（H 85 / H 150） |
| 文化、歷史 | 朱、赭、墨（H 30–50） |
| 食品、餐飲、烘焙 | 暖橘、番茄紅、焦糖（H 35–65） |
| 製造、工程、硬體 | 鋼藍、安全橘（H 235 / H 45） |

3. **套進風格 OKLCH 範圍產生三組**：
   - **貼題**：直接對應主題色相。
   - **沉穩**：同色相降彩度或鄰近偏移 ~30°，或風格允許時用無彩色（墨黑／紙白，總結內文改說明灰以保重點辨識）。
   - **外卡**：對比色或意外但說得通的方向，仍遵守規則與禁紫。
4. **跑腳本自動驗收**（必跑）：

```bash
python3 <skill>/scripts/oklch.py --palette --bg '#F1EFEA' --focus '#0D6B4F,#1F4FBF,#1F2328' --alert '#B5381F' --min-contrast 3.0
```

自動檢查項目：
- 非純白／純黑底色
- 焦點色對底色對比達標（≥24px 用 `3:1`，小字 `4.5:1`）
- 沒有紫色主調（`H 280–335`）
- 焦點色與警示色色相差 `≥ 60°`（無彩色免檢）
- 三組配色彼此 `CIELAB ΔE ≥ 15`（肉眼明顯不同）
