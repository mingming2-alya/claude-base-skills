# Style DNA：插畫場景（`illustration`）

> **一句話定位**：用摸得到、會說故事的物件與場景承載內容，十五種畫風可整套切換。
> **適合**：知識分享、新人引導、內部宣導、科普、故事型演講、活動流程。
> **避免**：密集財務報表、高密度多欄比較（這類改用 `counsel`）。
> **參考基準**：`outputs/illustration-integration/sheet5.jpg`（15 種畫風淺深雙底融合版）與《AI 的第三次搬家》。

## 1. 十二條融合規則（所有畫風共通）

1. **物件說故事**：每個物件必須對應這頁內容（不放隨機裝飾）。
2. **背景是一個地方，全頁同源底材**：桌面、房間、岩壁、宣紙、樹皮紙、畫布貫穿全頁；文字區把紋理放淡，**不換材質、不硬切一塊平白矩形**。
3. **同一個面、同一個光源**：所有物件坐在同一平面、投影方向一致（預設左上打光）。
4. **包圍，不並排**：物件至少從三邊切入或包圍文字；**禁止左文右圖直線分界、禁止把插畫框成一幅掛畫貼在文字旁**。
5. **文字在場景裡**：依版面 A／B／C 讓文字直接坐落於場景平面、畫中載體或對應物件旁。
6. **元素同材質，分隔與編號同筆觸**：徽章、編號、分隔線與框飾一律採該畫風的材質與筆觸。
7. **比例一致**：物件維持真實相對比例，不為了填空硬放大。
8. **物件與文字結構互動**：階梯對應步驟、分格對應階段、路徑走過地點、標註線連到零件，畫與字講同一個結構。
9. **高紋理畫風用內生題箋**：梵谷、吶喊、浮世繪等密集筆觸畫風，用畫中自然載體承載文字（和紙題箋、木牌、微半透明釉）。
10. **同一個色調家族**：底色與物件落在同一明度／彩度帶，輔助色可換色相但不跳調。
11. **一份簡報只用一種畫風**，不混用寫實照片與插畫，不使用受版權保護的知名卡通角色。
12. **零等待程式版＋可選 AI 升級插槽**：先用程式（SVG/CSS）一次畫出完整可看版；將整頁場景層包進 `<div class="asset-slot" data-slot="sXX-scene" data-mode="light|dark">...</div><!-- /slot -->`，同時輸出可選的 `IMAGE_UPGRADE.md`，使用者想升級時丟進無字底圖即可無縫替換、保留真文字層與動態。

## 2. 三種融合版面（A 為主，B、C 依內容穿插）

| 版面 | 做法 | 何時使用 |
|---|---|---|
| **A 全景環繞**（預設） | 整頁是一個連續平面，物件從四邊伸入並被畫邊裁切，文字寫在中央留光區 | 概念說明、一般條列、主張配說明 |
| **B 文字在物件上** | 文字寫在場景裡的載體（佈告欄、和紙題箋、木牌、微半透明釉、看板） | 封面標題、重點清單、**高紋理畫風必用** |
| **C 內容住進場景** | 條列拆開，每一項文字站在它對應的人物、步驟台階、分格或零件旁邊 | 人物介紹、步驟流程、地點路線、時間軸、零件標註 |

## 4. 明暗與用色規則（OKLCH；變暗不等於夜晚）

- **變暗只有兩種合法做法**：**換光線**（拉百葉窗、檯燈、油燈、火把、放映廳暗燈、地下關卡）或**材質本身的深色款**（黑色圖畫紙、深灰素描紙、烏金拓、藍摺絵、深色樹皮紙、墓室深藍）。
- **時間記號跟著內容走**：月亮、星星只在內容本身發生於晚上（如尾牙）才畫；白天主題的深色版不畫星月。
- **B 版面載體跟著變深**：深色版時題箋、木牌、釉一起轉深並配淺字；原本的黑線在暗底改用該材質會用的淺色（白蠟筆、白鉛筆、白色墨水、石灰白、白黏土）。
- **實測範圍**：
  - **淺色版**：底 `L 0.87–0.96, C ≤ 0.05`｜文字 `L 0.25–0.34`｜次要 `L 0.44–0.55`｜強調色（≥24px）`L 0.42–0.58, C 0.12–0.19`（對底 `≥ 3:1`，建議 `≥ 4.5:1`）。
  - **深色版**：底 `L 0.21–0.31, C ≤ 0.06`（梵谷深鈷藍天空至 0.40，字寫在加深釉上）｜文字 `L 0.93–0.97`｜次要 `L 0.77–0.84`｜強調色 `L 0.66–0.84, C 0.11–0.16`（對底 `≥ 5:1`）。
  - 深色底上**不可用 `mix-blend-mode: multiply`** 疊顏料（會整片消失），改正常覆蓋。

## 6. 動效個性（Phase B 接軌）

- 紙黏土／剪紙／像素採輕量逐格手感（`steps(5)` 或微彈性定格）；手繪／水彩／場景物件可做緩慢微浮動或視差進場。
