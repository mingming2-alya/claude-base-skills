# 視覺指引規格書（Visual Guidance Spec — v4.4）

> **核心信念**：動態不是為了讓畫面「都在動」，而是替觀眾拿著一把無形的手電筒——**靜態看懂主從與因果，動態跟上先後與轉折，光暗與空間形塑舞台呼吸。**
>
> 本規格書定義 `deck-architect` 的**場合視覺節奏、去框化與靜態動線原型、動態視線導演原則與雙軌節拍／媒體規範**，與 `references/motion-system.md`（60fps 技術底盤）互為表裡。

---

## 一、第一性原理：七種「假指引」反模式

撰寫自由畫布頁時，以下七種反模式**一律避免**，改採右側正解：

| 反模式 | 觀眾體感 | 正解 |
|---|---|---|
| **1 秒一鍋端／過快難閱讀** | 全頁 4 拍在 1–2 秒內飛速演完，每拍只停 0.7 秒，觀眾來不及讀焦點就跳走 | **每拍至少停留 1.3–1.8 秒**（多階段複雜頁總長 **3.8–5.6 秒**；封面／震撼頁 1.6–2.4 秒），同一時刻只有 **1 個主動視覺焦點** |
| **跨螢幕乒乓／四散跳躍** | 左上 → 右上 → 左下 → 右下交錯跳動，或看板讓正常項目四散角落 | **先空間分群、再單向流動**：如左欄「風險 ↓ 拍板」垂直閉環 → 右欄「健康總覽由高到低」群組，**絕不回頭跳躍** |
| **手機隱形光環** | 用 10px 細微 `box-shadow` 標示重點，縮至 390px 手機（~0.2×）幾乎看不見 | 採 **聚光＋非焦點壓暗**（配角退至 `opacity: 0.26–0.32`＋主角高反差描邊與 `≥ 20px` 舞台等效外光暈） |
| **孤點提前漂浮＋虛線拉扯** | 引導線還沒畫出，末端圓點先懸在半空；或對 0 寬度 SVG `<line>` 用 `scaleX/Y` 導致失效 | 嚴守 **「起點亮 → 線描出 → 終點綻放＋波紋 → 標註亮」**；實線用 SVG `<path data-draw>`、虛線直線用 HTML `data-wipe` |
| **只淡入結果、不演因果** | 數據改善頁或風險看板直接把「最終結果」靜靜淡入，看不出「改了什麼」 | 用 **因果現場演變**（`data-transform-at` 舊態轉新態）與 **實體因果箭頭**（從風險卡正下方垂直指入拍板卡） |
| **移動球劫持視線（Motion Capture）** | 在多站時間軸上放一顆連續跨站滑行的亮球，觸發平滑追視反射而忽略文字與插畫 | 採 **分段橋接軌線（Segmented Bridge Rail）**：每站停留閱讀期間保留 **0.6–0.9 秒完全靜止閱讀窗**，僅在換站 300–400ms 過場瞬間鋪出下一段連接軌線 |
| **轉場花招凌駕閱讀順序** | 試算頁讓右側結果數字搶先從前頁飛入再跳回左側條件；或產品頁左右兩欄同時搶跑 | **內容語意順序永遠高於轉場花招**：產品頁守「輸入與做法 → 預報結果 → 業務成效」；試算頁守「左條件 → 箭頭 → 右結果」純單向流 |

## 二、場合導向的光暗極性節奏與去框化紀律（v4.4 新增）

依 `brief.md` 拍板的 `stage_mode`（詳見 `contexts.md`）動態調配明暗與邊框，**絕不把所有簡報做成同一種暗色圓角卡片**：

### 1. 光暗極性節奏（Per-Slide Polarity Cadence）
- **`briefing`（`single` 單一主調）**：全場鎖定單一 `light` 或 `dark` 底色，確保決策與週報高速掃讀的視覺穩定性。
- **`pitch`（`accent-invert` 局部反轉）**：正文維持主調，在原話見證、關鍵對比或震撼轉折切換反極性，製造記憶點。
- **`keynote`（`bipolar` 光暗雙極呼吸）**：把極性當敘事與認知切換器——**亮棚（`light`）**承載理性規格、實物剖面與工具流程；**暗場（`dark`）**承載開場、章節大扉頁、影音、原話暗房、發光信號與情緒震撼；**分割（`split`）**與**照片（`photo`）**承載收斂總結與團隊溫度。避免連續 >5 頁同極性同構圖，讓每次切黑都保有「突然關燈」的舞台衝擊力。

> *實作語法*：在 `storyboard.yaml` 單頁寫 `surface: light|dark|split|photo` 或於自由畫布 `<section class="slide canvas" data-surface="...">` 宣告，底盤自動套用 `--light-*`／`--dark-*` 雙極配色並同步反轉導航外殼，再由 `check.mjs --motion` 驗證亮度拉開與逐頁像素 WCAG 對比。

### 2. 去框化紀律（Anti-Card-itis）與五大進階編輯原型
在 `pitch`（半去框化）與 `keynote`（≥40–50% 內容頁無圓角卡片框）場合，優先以留白、尺寸反差、細線與實物建立階層，避免「大框包小框」的後台監控感。除既有四大動線原型外，擴充五大進階靜態原型：

1. **白棚無框實物剖面＋裸排巨數**：純淨亮底直接擺高精細產品爆炸圖／透視圖，周圍零卡片框，以 `54–80px` 粗數字＋小灰標直接呼吸於物件旁（適用硬體、架構、工藝拆解）。
2. **羽化融圖 Bento＋中央反極性 Hero 格**：淺底圓角格內嵌入實拍特寫，圖片邊緣採漸層羽化（Soft Edge Fade）溶進卡片底色，與巨數共生；中央一格反轉深底放置產品 Hero 照鎖死焦點。
3. **35/65 深色錨點分割＋極淨細線清單**：左 35% 實色深炭灰錨點欄放大字章節標題（如「三個戰功」「兩個協作」「一個挑戰」），右 65% 極淨亮底僅用 `1px` 淡灰橫線分隔數據行、零卡片框。
4. **自然物象軌跡構圖（Metaphor-Driven Spatial Layout）**：讓單一連續場景中的物理弧線（如火箭升空軌跡、河流、光束、山脊）本身成為時間或階段座標軸，文字以極細垂線掛載於軌道沿線，杜絕「美圖上硬蓋三張圓角框」。
5. **全黑暗房原話見證（Verbatim Theater）＋全出血照片牆＋無框光學信號燈**：
   - 原話見證：左 60% 暗場完整保留客戶／使用者逐字原話（不縮成一行小註腳），右 40% 高反差亮塊提煉 3 條心法。
   - 團隊溫度：全出血照片拼貼牆（Photo Mosaic）搭破格橫帶巨字。
   - 健康度體檢：暗場懸浮三顆柔和發光信號球（綠保持／黃關注／紅預警），下方無框條列並對關鍵缺口局部著色。

## 三、四大靜態視覺動線原型（Static Eye-Flow Archetypes）

**底線規則：關掉動畫（`?still=1`／列印 PDF）時，版面構圖與連結符號依然能引導視線；雙欄／儀表板頁面左右兩欄須對齊同一條底部基線（約 `y = 960–1014px`），不留失衡空洞。**

1. **分區因果流（Left Action Spine → Right Overview / Cause → Delta → Effect）**
   - **適用**：多店／多專案 Bento 進度看板、數據改善故事頁、前後對比。
   - **靜態骨架**：同類必成群——例左欄「唯一風險卡正對正下方拍板卡（同寬＋垂直中軸因果箭頭）」＋右欄「健康卡由總覽 → 高進度 → 低進度由上而下整齊排開」。
   - **動態導演**：先定格「舊態／唯一風險」停留 **1.4–1.8 秒**（配角壓暗退後）→ 演繹因果變化或畫垂直箭頭指向解法 → 視線平移至右側群組，演畢 100% 回復平衡完稿。
2. **產品因果展開流（Input & Action → Product Result → Business Impact）**
   - **適用**：產品介面展示、系統核心架構圖。
   - **靜態骨架**：裝置內外標註**左右語意一致**——左半對左外標講「怎麼算／輸入與動作」，右半對右外標講「算出的結果與量化成效」。
   - **動態導演**：三拍獨立由左向右單調聚光——Stage 1 輸入與動作 → Stage 2 預報結果（描線＋端點波紋）→ Stage 3 量化業務成效。
3. **時間／流程分段流（Station Hold → Bridge Rail → Next Station）**
   - **適用**：插畫場景三站、時間軸、作業流程步驟。
   - **靜態骨架**：貫穿全站的水平時間細軌拆成各站間分段線，每站垂直對齊對應物件形成 T 型閱讀格線。
   - **動態導演**：每站依序獨立聚光 → 虛線引導針由上往下掃落（`data-wipe="down"`）→ 觸及物件綻放波紋（`data-ripple`）→ **留足 0.6–0.9 秒完全靜止閱讀窗** → 換站瞬間才以 350ms 鋪出下一段橋接軌線。
4. **控制→結果聯動流（Left Control → Causal Arrow → Right Live Output）**
   - **適用**：現場互動試算器（ROI／資源分配模擬）、參數推演頁。
   - **靜態骨架**：左操作與右結果頂底雙邊對齊，兩欄間以方向箭頭建立「調左變右」心智模型。
   - **動態導演**：切頁採平順橫移 → Stage 1 先聚光左側條件並輕微提示可拖曳（`data-nudge`）→ 畫出左→右因果箭頭 → Stage 2 一次亮起右側完整結果；使用者提早互動立即解除壓暗並即時重算。

## 四、動態節奏、雙軌節拍與雙軌媒體原則

### 1. 動態節奏與高反差四條鐵律
1. **一拍一主角、從容可讀＋閱讀期零干擾**：每拍焦點 ≥ 1.2 秒（建議 1.3–1.8 秒），動作結束後留 0.6–0.9 秒完全靜止閱讀窗；多階段頁總長 3.8–5.6 秒；永遠支援零鎖死打斷。
2. **高反差聚光＋三層明暗狀態（`data-focus-plan`）**：當拍 `.focus-active`（`1.0`＋高反差框與 `≥ 20px` 外光暈，群組／浮空字加 `data-focus-style="clean"`）、已演完 `.focus-visited`（`0.78–0.84`）、未出場 `.focus-dim`（`0.26–0.32`）；演畢／打斷／互動搶先操作 100% 自動歸零復原。
3. **線先到、點後綻、字再亮**：實線用 SVG `<path data-draw>`（座標順視線方向）；虛線與刪除線用 HTML `data-wipe`；端點圓點與箭頭加 `data-pop` 於線條抵達瞬間綻放。
4. **100% 確定性靜態終態**：HTML 原始 DOM 永遠為最終正確狀態（`?still=1`、`B` 鍵、列印與 `check.mjs` 永遠檢核完整終態）。

### 2. 雙軌節拍契約（Auto-Choreography ＋ Presenter-Paced `data-step`）
- **自動視覺指引（預設，全模式適用）**：90% 以上頁面維持「一鍵翻一頁」零負擔直覺契約，頁內透過自動聚光與描線引導視線。
- **講者可控點擊步進（`data-step` / `data-step-hide` / `data-step-only`，限 `pitch`／`keynote` 關鍵 1–3 頁）**：用於**需要講者配合口白停頓、製造懸念與逐層拆解**的頁面——例如單頁多層換幕總圖、轉折公式滑入補完、照片牆壓出主題字或壓軸金句落幕。按 `→` 逐步揭曉（步進內部 `data-draw`/`data-count` 同步延遲觸發）、尾步後翻下頁、回翻落於終態；`?still=1` 與列印自動展開最終態。

### 3. 雙軌影音與活 Demo 原則（按需模組自動注入，未用到 0 KB）
- **真實影片與實證音檔（`media` 按需模組）**：開場大片、工廠實拍與實測降噪音檔透過外部相對路徑掛載 `<video data-slide-video>`（`assemble.py` 僅內嵌 `poster`、絕不轉 Base64）與 `<audio data-sound-demo>`（36 條動態波形＋A/B 互斥播停），翻頁與靜態自動停播歸零。
- **產品流程展示與照片輪播（`flow-carousel`／`coverflow` 按需模組）**：AI／產品流程示範（`[data-flow-carousel]` 垂直輪播卡＋步驟切換）與團隊／場域照片 3D CoverFlow 輪播（`[data-coverflow]`），以輕量原生 HTML/CSS/SVG 實作並按需注入，比預錄 MP4 更銳利、零檔案膨脹且可現場點擊切換。

| `data-beat="1\|2\|3\|4"` ＋ `data-from` | 語意分拍方向進場 | `left\|right\|up\|down\|none` | 正常顯示 |

## 六、Step 5 視覺指引品管清單（人工＋`check.mjs --motion`）

1. **場合節奏與去框化**：明暗極性與去框比例是否符合 `brief.md` 的 `stage_mode`？`keynote` 是否避開連續 5 頁以上同質暗色圓角卡片？
2. **三秒靜態動線**：關掉動畫（`?still=1`）看截圖，視線是否仍自然從主角流向結論／拍板點？
3. **零同時混戰與手機可辨識**：動態進場時同一時刻僅 1 個主焦點、無左右乒乓；390px 手機下聚光壓暗與因果箭頭依然一眼清晰。
4. **線點時序零破綻**：端點圓點只在線條抵達瞬間綻放，虛線銳利無拉扯。
5. **零殘留復原**：整頁演完與快按方向鍵打斷後，`.focus-*` 與 `.pre-transform` 100% 歸零復原（`check.mjs --motion` 自動實測）。
6. **去小字不回潮**：視覺指引靠光影、反差、線條、波紋與微動傳達，不為引導加回冗餘第 3 層小字（合法豁免之原話暗房與產品情感主標除外）。
