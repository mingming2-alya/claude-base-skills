# 視覺指引與空間動線規格書（Visual Guidance Spec — v5.0）

> **核心信念**：動態不是讓全頁同時閃爍，而是替觀眾拿著一把從容的手電筒——**靜態三秒看懂主從與因果，動態以人類呼吸節奏帶走視線，光暗與留白形塑高級秩序。**
>
> **靜態上限 × 動態上限融合鐵律**：每一頁即使定格於 `?still=1` 或列印成 PDF，都必須具備該風格的 1920×1080 靜態美感上限（溫潤畫廊秩序、現代因果 Bento、微光舞台艙體、無字插畫底圖融真字）；動態原語直接寄生在原生幾何結構上，演畢即完全靜止（零永動干擾）。底盤技術參數與原語語法統一見 `references/motion-system.md`。

## 一、七種「假指引」反模式與正解

| 反模式 | 觀眾體感 | v5.0 正解 |
|---|---|---|
| **快切閃現／一鍋端淡入** | 35–50ms 飛速刷出或全頁同秒淡入，眼睛根本來不及對焦 | **全風格統一從容慢板**：描線／生長 `800–1,200ms`、交錯 `220–320ms`、每拍停留 `1.4–1.8s` |
| **跨螢幕乒乓／超過 4 區碎裂** | 左上 → 右上 → 左下跳動，或切出 6–8 個瑣碎小框 | **嚴守 `slide_plan.zones ≤ 4`**：先空間分群，再沿 `1 → 2 → 3` 單向流動，絕不回頭跳躍 |
| **提早破梗／聽讀分心** | 講者還在講問題池，右邊最終結論與數字已經全亮搶走目光 | `talk`/`discuss` 單頁具 **≥3 個依序推導區塊**時，果斷啟用 **`data-step`（≤5 拍）** 隨口白逐拍揭曉 |
| **孤點提前漂浮／無效容器描線** | 引導線還沒畫到，末端圓點先亮；或把 `data-draw` 誤掛在 `<g>` 上失效 | 嚴守 **「起點亮 → `<path data-draw>` 描出 → `data-pop` 終點綻放 → 標註亮」** |
| **只淡入結果、不演因果壓縮** | 45 天 → 12 天或風險改善只靜態擺結果，看不出收斂過程 | 用 `data-transform-at`（保留 **`0.6s` 舊態停頓**後柔緩演變）或實體漏斗／因果箭頭直指拍板區 |
| **移動球劫持視線** | 時間軸上放連續滑行亮球，觀眾只盯著球跑而漏讀內容 | 採分段橋接軌線，每站保留 **0.6–0.9 秒完全靜止閱讀窗** |
| **塞滿解釋小字充當指引** | 因怕聽眾看不懂而在卡片裡塞第 3、4 層長句註解 | **圖代字（`visual_encoding`）**：用比例高度、漏斗寬度與雙語意色說話，每卡 ≤2 層字，口白歸 `notes` |

## 二、光暗極性、色彩面積平衡與去框化原型

### 1. 光暗極性節奏（Gate 2 依 `stage_mode` × 風格定案）
- **`briefing`（`single` 單一主調）**：全場鎖定單一 `light`（預設）或 `dark` 底色，維持決策與匯報高速掃讀穩定感。
- **`pitch`（`accent-invert` 局部反轉）**：正文維持主調，在關鍵原話見證、核心轉折或對比頁切換反極性創造記憶峰值。
- **`keynote`（`bipolar` 光暗雙極呼吸）**：亮棚（`light` 承載規格與機制）× 暗場（`dark` 承載開場、大扉頁、影音與震撼）× 分割／照片（`split`/`photo`）交錯，避免連續 >5 頁同極性同構圖。

### 2. 75–20–5 面積平衡與三階字重呼吸
- **拒絕重黑壓迫**：在 `mode: light` 亮底頁面，保持 **≥75% 溫潤底紙與次級淺卡（`--bg`／`--bg-2`）**、**15–20% 細線與結構脈絡**、**5–10% 主／次語意焦點色（`--accent`／`--accent-2`）**，絕不在亮底硬塞大塊死黑背景。
- **三階字重對比**：主標題 `600–800` ＞ 關鍵數值 `700–800` ＞ 標籤與短錨點 `400–600`，杜絕全頁 `900` 粗黑字體造成視覺窒息。

### 3. 去框化紀律（Anti-Card-itis）與五大編輯原型
在 `pitch`（半去框）與 `keynote`（≥40–50% 無圓角卡片框）優先選用：
1. **白棚無框實物／幾何剖面＋裸排巨數**：零外框，大數字與細引導線直接呼吸於主圖旁。
2. **羽化融圖 Bento＋中央反極性 Hero 格**：特寫邊緣柔和溶入底色，單一主角格反轉極性鎖定焦點。
3. **35/65 錨點分割＋1px 細髮絲清單**：左 35% 錨定核心主張，右 65% 極淨細線分隔數據列、零層層套框。
4. **自然物象／收斂漏斗軌跡構圖**：讓漏斗流向、時間弧線或階梯本身成為座標軸，文字掛載於軌跡節點。
5. **原話暗房（Verbatim Theater）＋全出血照片牆**：真實逐字原話獨立成區（合法豁免字數限制），不縮成小註腳。

## 三、四大靜態視覺動線原型（`zones ≤ 4` ＆ 底部基線齊平）

**硬底線**：多欄或 Bento 頁面，左右分區底部必須收齊在同一條視覺基線（約 `y = 960–1014px`），不留塌陷空洞。

1. **分區因果流（Cause / Funnel → Mechanism / Triage → Outcome）**
   - 適用：戰術收斂總覽、多專案 Bento 看板、前後差距。
   - 骨架：左區放輸入池／唯一風險卡 → 中央漏斗或垂直因果箭頭 → 右區放分工矩陣、健康總覽或拍板選項。
2. **產品／系統展開流（Input & Action → Core Engine → Business Impact）**
   - 適用：工具實證、系統架構、AI 流程拆解。
   - 骨架：由左至右單向對應「輸入條件 → 系統處理／介面實證 → 量化產出」，內外標註方向一致。
3. **時間／站點分段流（Station 1 → Bridge Rail → Station 2 → Station 3）**
   - 適用：年度路線閉環、插畫場景站點、教學演練步驟。
   - 骨架：水平或階梯分段軌連接 3–5 個站點，形成清晰 T 型閱讀格線。
4. **控制→結果即時聯動流（Left Control → Causal Arrow → Right Live Output）**
   - 適用：現場試算器（`.live-ctrl`）、A/B 切換實證。
   - 骨架：左欄參數控制對齊右欄動態圖表，使用者一操作立即解除壓暗並即時重算（`~200ms` 跟手回饋）。

## 四、`0-step` 與 `data-step` 正交判準（步進與慢板脫鉤）

**「動畫播放速度（全風格統一從容慢板）」與「是否按鍵停頓（`data-step`）」是兩個完全正交的決定**：

| 維度 | 預設 `0-step`（自動從容展開） | 講者步進 `data-step`（按 `→` 逐拍揭曉，`N ≤ 5`） |
|---|---|---|
| **預設適用場合** | `briefing` 日常匯報、`delivery: read` 自行閱讀，或單一視覺焦點頁 | `talk` 上台講、`discuss` 會議討論中需要配合口白推進的複雜頁 |
| **啟用判準** | 頁面可在 3 秒內一眼掃完（如封面、巨數宣言、單純雙欄對照） | 單頁含 **≥3 個依序推導區塊**（如「問題池 → 收斂機制 → 落地實績 → 下階段閉環」、公式推導、正反案例揭曉），一次全亮會**提前破梗**或讓台下分心先讀後面 |
| **動畫體感與驗收** | 進頁按 `220–320ms` 交錯與 `800–1,200ms` 描線自動優雅就位 | 每按一次 `→`，容器先以柔緩曲線浮現，內部數字滾輪／描線自動等待 `revealDelay (~340ms)` 後才精準開跑；`check.mjs --motion` 自動測試全步進並輸出 **`check/filmstrip-sXX.jpg`（`Step-0 / Mid / End` 分鏡條）** |

## 五、Builder 自檢與單輪只讀 Critic 審查清單

Gate 2a、Gate 2b 與 Gate 3 送審前，先確保 `check.mjs` **0 個工程錯誤**，再由乾淨只讀 Critic 對照 `slide-*.jpg`、`filmstrip-sXX.jpg` 與 `slide_plan` 檢查以下 5 點（每關最多自修 1 輪）：

1. **去贅字與圖代字落實度**：是否嚴守 `slide_plan.anchors` 與每卡 ≤2 層字？有無可改畫成圖解或移入 `notes` 的解釋長句（參考 `lint.py` 軟性提醒）？
2. **三秒靜態動線與底部基線**：看 `slide-*.jpg` 靜態截圖，視線是否自然沿 `zones` 單向流動？雙欄底部是否齊平無空洞？
3. **字重呼吸與色彩面積**：是否具備三階字重層次（無全頁 `900` 粗黑）？亮底是否維持 ≥75% 溫潤留白、無突兀死黑塊或超過雙語意色的雜亂彩虹？
4. **步進分鏡條零破梗、零搶跑**：看 `filmstrip-sXX.jpg` 的 `Step-0 / Mid / End`，`Step-0` 是否乾淨隱藏後續推導（含巢狀區塊）、`Mid` 與 `End` 揭示順序是否符合口述邏輯？
5. **跨頁構圖節奏**：相鄰兩頁構圖是否有清晰呼吸變化（同 `series` 除外）？主標題是否永遠為該頁最大路標字？
