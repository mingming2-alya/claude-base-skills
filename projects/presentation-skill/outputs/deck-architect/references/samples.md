# 視覺關卡（Gate 2）：三款多元風格樣張與主題配色

## 核心原則

1. **一次決定風格與構圖（不再分兩步）**：結構（這頁的東西是什麼關係）已在 `storyboard.yaml` 定案；畫面（構圖、四層、材質、字體、色彩）屬於風格本身，必須一起設計、一次呈現，才不會像套死模板。
2. **讓人眼睛一亮覺得「哇就是這些！」**：三個方向要在**調性、構圖骨架、明暗、字體聲音與視覺媒介**上徹底拉開，絕不可只換顏色與字體。
3. **只鎖用色規則，依主題動態推薦三組配色**：見 `styles/color-system.md`，用 `scripts/oklch.py --palette` 自動驗證。

## 步驟一：從多元風格池挑三個方向

讀 `styles/index.json`，依 `brief.md` 的主題、受眾與場合挑出三個對比強烈的方向：

- **穩健**：最貼合簡報場合與聽眾期待、最容易過關。
- **大膽**：同樣貼題，但更有張力、記憶點更強。
- **驚喜**：使用者沒主動想到、但視覺比喻與題材一拍即合（若選 `illustration`，同時挑選最貼題的一種畫風，如紙黏土、素描、8bit 像素、浮世繪等）。

> Phase A 目前完整 Style DNA 已就緒的為首批三款：`counsel`（顧問報告）、`apple`（Apple 發表）、`illustration`（插畫場景，含 15 種畫風）。若主題高度適合尚未寫完憲法的其他 9 款之一，可依 `styles/index.json` 定位與 `outputs/style-moodboard-v5/` 視覺錨點作為「驚喜」候選，並清楚標註。

**反雷同檢查**：三個方向不能同時都是「白底＋無襯線＋左文右圖」。至少拉開明暗（一淺一深或不同材質底）、主視覺形式（色塊數據 vs 舞台光影 vs 融合插畫）與構圖重心。

## 步驟二：挑選樣張頁面（嚴格 2–3 頁）

樣張**不可超過 3 頁**（4 頁並排每格過小、看不清細節）。優先順序：

1. **招牌頁**（必填）：優先挑標記 `signature: true` 的頁面；若未標記，挑整份簡報論點或數字最核心的一頁。
2. **封面**（或一頁總覽 `pillars`）：展現整體第一印象與字體聲音。
3. **第三頁（選填，湊滿 2–3 頁）**：挑與招牌頁**內容形狀不同**的一頁（例如有震撼頁就用震撼頁；有步驟／流程／比較就挑它）。

使用**使用者真實的標題與內文**，嚴守「主標題最大、總結在內文」。

## 步驟三：自由編排樣張＋三組 OKLCH 主題配色

在 `decks/<name>/samples/` 裡為三個方向各建立 1920×1080 獨立 HTML 樣張（例如 `a-counsel.html`、`b-apple.html`、`c-illustration.html`，或每個方向 2–3 張），並撰寫 `samples/manifest.json` 標明各組標題、調性理由與每張說明。

同時決定建議明暗（`light`／`dark`）並依 `styles/color-system.md` 準備三組主題配色（貼題／沉穩／外卡），務必先跑：

```bash
python3 <skill>/scripts/oklch.py --palette --bg '<底色>' --focus '<貼題>,<沉穩>,<外卡>' [--alert '<警示色>']
```

> 呈現策略：
> - 若使用者尚未選風格：先給 **3 款風格樣張並排**（各套該風格的貼題配色與建議明暗），並在說明裡附上「選定風格後可切另一種明暗與另外兩組配色」；或在同一張對照表下方直接展示推薦主打風格的三組配色變體。
> - 若使用者已指定風格：直接呈現「所選明暗（或淺／深兩版）× 三組主題配色」並排。

## 步驟四：組裝對照頁並執行像素級自動品管

```bash
python3 <skill>/scripts/assemble.py --sheet decks/<name>/samples --title "<簡報標題>｜風格樣張"
node <skill>/scripts/check.mjs --sheet decks/<name>/samples
```

`check.mjs --sheet` 會逐張檢驗所有樣張的真實像素 WCAG 對比（含漸層字）、主標題≥總結、溢出、最小字級、SVG 重複 ID 與腳本錯誤，輸出 `img/*.jpg` 與高解析 `sheet.jpg`。

## 步驟五：自我驗收再送交使用者

交給使用者前，**親自打開 `samples/sheet.jpg` 檢查**：

1. **真的不同嗎？** 想像轉成灰階，三款的構圖重心、主視覺與留白節奏仍一眼分得出來嗎？
2. **主標題是不是最大？** 每張畫面上最先被看到的字必須是這頁的題目，不是總結。
3. **零報錯嗎？** `check-report.md` 全部 `OK`，沒有文字被裁切或重疊。

確認通過後，用**互動表單**請使用者選擇風格、明暗（淺／深）與配色方向，**停下來等回覆**。
