# 情境判斷與製作模式

同一套流程要能處理週會，也要能處理年會開場。差別在於「力道」，不在流程。

## 五個維度（在 Grill 中順便判斷，寫進 brief）

| 維度 | 選項 | 影響 |
|---|---|---|
| 目的 | 告知 / 說服 / 啟發 / 促成決策 / 慶祝 | 架構方向、要不要震撼頁 |
| 播放情境 | 上台講 / 會議中討論 / 對方自己讀 / 自動播放 | 每頁字數、要不要講者備註 |
| 信任來自 | 數據 / 故事 / 氛圍 | 版型選擇（`number`、`compare` vs `quote`、`point`） |
| 受眾關係 | 內部 / 外部客戶 / 公開觀眾 | 正式程度、主題選擇 |
| 製作節奏 | 一次性 / 定期更新 / 一套多版本 | 是否沿用上次的主題與結構 |

類型只是這五個維度的常見組合，不要把它們當成固定分類：

| 常見類型 | 典型組合 | 震撼頁 | 每頁密度 |
|---|---|---|---|
| 會議簡報 | 促成決策・會議討論・數據・內部 | 0 | 中高 |
| 客戶洽談 | 說服・會議討論・數據＋故事・外部 | 0–1 | 中 |
| 商業提案 | 說服・上台講・數據＋故事 | 1 | 中 |
| 年度成果 | 告知＋啟發・上台講・數據 | 0–1 | 中 |
| 新知科普 | 告知＋啟發・上台講・故事 | 1 | 低 |
| 經驗分享 | 啟發・上台講・故事 | 1–2 | 低 |
| 個人成長 | 啟發・上台講・故事＋氛圍 | 1–2 | 低 |
| 活動開場 | 慶祝・上台或自動播放・氛圍 | 2 | 極低 |

「對方自己讀」的版本沒有講者補充，每頁可以多一些說明文字，講者備註可以省略。

## 兩種製作模式

### 快速模式（週會、臨時會議、使用者說「趕時間」）

- Grill 壓到 5 題以內：目的、對象、時長，然後直接提出 1–2 個架構候選。
- 跳過三種風格樣張：沿用使用者上次用的主題；沒有上次就用 `paper`，並在交付時說明可以換。
- 起點、終點、架構三件事**不可省略**，這是這個技能的核心價值。

### 標準模式（預設）

完整流程，三個關卡都要停。

由你依情境推薦模式，使用者可以直接指定。
