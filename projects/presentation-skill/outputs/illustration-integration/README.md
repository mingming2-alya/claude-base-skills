# 插畫場景：背景與元素為什麼分家，三種融合版面

_2026-11-19。使用者回饋：「插畫場景最大的問題可能是排版吧，背景與元素還是有點剝離感，沒有合到一起。」_

`sheet.jpg` 是對照：原版（v5 紙黏土）與三種融合版面。三種都用同一頁內容、同一套紙黏土材質（`src/clay.js`）、同一個左上光源，只改版面。

## 診斷：為什麼分家

拿使用者的參考簡報《AI 的第三次搬家》對照。那份簡報融入的原因有四個：

- 背景沒有硬邊界。
- 物件從外圈包住文字。
- 卡片與陰影是同一種材質。
- 物件與主題對應。

十五種畫風各自犯了下面幾項：

| 原因 | 出現在哪些畫風 |
|---|---|
| **左文右圖**：文字半邊是空底，圖都在另一半，中間有一條看得到或感覺得到的直線分界 | 幾乎全部，最明顯的是埃及、漢畫像石、瑪雅、浮世繪、吶喊 |
| **把場景框成一幅畫**：場景被邊框、分欄、圓框圍成一幅獨立的畫，貼在文字旁邊 | 埃及（三層分欄）、漢畫像石（拓片邊框）、瑪雅（摺頁）、復古卡通（圓框）、浮世繪（直切的版畫） |
| **物件沒有共同的地面**：物件浮在半空，影子落在一片漸層上 | 紙黏土（馬克杯、便利貼）、手繪、霓虹 |
| **背景不是一個地方**：只是一片漸層或紙紋，看不出這是桌面、牆面還是地板 | 紙黏土、手繪、霓虹，以及多數紙底畫風的左半邊 |
| **徽章與場景無關**：條列的頭像圓點不是場景裡的東西 | 紙黏土、手繪、霓虹（新畫的十二種已改成各自材質的徽章） |

## 融合規則（草案，等使用者選版面後寫進規格）

1. **背景是一個地方**：桌面、牆與地板、佈告欄、壁面，不是抽象漸層。
2. **物件在同一個面上**：影子落在同一個面，光從同一處來。
3. **包圍，不並排**：
   - 物件分布在至少三個邊，被畫面邊緣裁切。
   - 不出現左文右圖的直線分界。
   - 不把場景框成一幅畫貼在旁邊。
4. **文字在場景裡**：三種寫法，就是三種版面。
   - A：寫在場景的平面上。
   - B：寫在場景裡的物件上。
   - C：站在它說明的物件旁邊。
5. **元素同材質**：徽章、卡片、膠帶、圖釘都用場景的材質與光影。
6. **比例一致**：物件照真實大小，不為了填空而放大。

## 三種版面

| 版面 | 做法 | 適合 | 代價 |
|---|---|---|---|
| **A 全景環繞** | 整張是一個面（這頁是俯視的桌面），物件從四邊進來，文字寫在中央的光裡 | 每一頁都能用，最像參考簡報 | 文字區仍是「空著的地方」，融合程度最溫和 |
| **B 文字在物件上** | 文字寫在場景裡的物件上（這頁是佈告欄上的紙與卡片），物件與牆、架子在同一個房間 | 標題頁、重點清單、需要很清楚的頁 | 每頁都是板子會單調，要換物件（看板、黑板、便條、螢幕） |
| **C 內容住進場景** | 條列拆開，每一項站在它說明的人或物旁邊（這頁是三個人各在自己的位置） | 人物、步驟、地點、時間軸 | 版面跟著內容變；要畫的東西最多 |

## 換到其他畫風會是什麼樣子

| 畫風 | A 全景環繞 | B 文字在物件上 | C 內容住進場景 |
|---|---|---|---|
| 埃及壁畫 | 整面牆都是壁畫，人物與分欄圍著文字區 | 文字寫在書記官攤開的莎草紙上 | 四個步驟各在一層分欄，說明跟著那一層 |
| 8bit 像素 | 整個畫面是遊戲世界，文字在天空 | 文字在 RPG 選單視窗裡 | 四關的說明站在各自的平台旁 |
| 漢畫像石拓片 | 拓片鋪滿全頁，文字在留白的榜題區 | 文字刻在畫像石的榜題框裡 | 每一站的說明跟著車隊裡對應的一段 |
| 浮世繪 | 版畫鋪滿全頁，文字在天空的漸層裡 | 文字寫在題簽與色紙形上 | 三件準備各配一個畫中物件 |
| 皮影戲 | 整片布幕就是舞台，戲偶從兩側進場 | 文字寫在戲台的匾額與布幔上 | 三幕各是一組戲偶，說明在下方 |
