# 何時列生圖清單

**目前待辦為零。** 十款樣張都能直接檢視。紙黏土的杯碟與集點卡使用 HTML/CSS 繪製。

當具體頁面需要某個效果，而現有素材與排版手段無法達成、確實需要生圖時，Agent 可把需要的圖片整理成清單。使用者負責生圖，Agent 負責定義需求、收到圖片後的整合與驗證。每次都依該份簡報的內容判斷。

| 清單欄位 | 要交代的事 |
|---|---|
| 頁次、用途與原因 | 這一頁要傳達什麼？缺少哪個必須生圖的效果？ |
| 畫面 | 主體、動作、建議提示詞，以及與該頁內容的關係 |
| 放置方式 | 畫面比例、建議尺寸、放置區與文字留白，是否需要透明背景 |
| 光線與配色 | 依本次入選風格指定色調、打光、陰影與材質 |
| 交回與驗收 | 檔名或交付格式，Agent 接圖後檢查裁切、佔位與文字可讀性 |

## 紙黏土範例

假設日後的演講指定手作黏土人物在櫃檯迎接熟客，且成品必須有該場景的細節，Agent 可以只列**一張主場景**。本例可指定約 4:5 的直式 PNG（建議 880 × 968），置放於右側。畫面用桃杏色與鼠尾草綠，左上打光，右下柔影；物件呼應熟客的偏好，文字保留在獨立文字層。

收到適用圖片後，放到同層的 `img/`，執行 `python3 make_board.py`。產生器會把圖片嵌入 HTML，離線開啟也可顯示。支援既有的檔名，每張可獨立提供。

| 檔名 | 對應位置 |
|---|---|
| `clay_scene.png` | 替換右側的程式繪製場景，依原比例容納 |
| `clay_obj_box.png` | 選用的右側場景左下角物件 |
| `clay_obj_ball.png` | 選用的右側場景右上角物件 |

本表是素材介面說明。實際使用哪幾張，取決於選定的效果。公開範例只使用可公開的素材。
