# 用色彈性示範（2026-11-18）

回答使用者的問題：「有沒有可能用色不定死？」可以。做法是**鎖規則，不鎖色碼**：每款風格寫明用色規則（有哪些顏色角色、各自的明度與彩度範圍、什麼不能動），換色只換規則允許的部分。

`sheet.jpg` 是首批三款各換三組配色的對照：

| 風格 | 不動的規則 | 示範的三組 |
|---|---|---|
| 顧問報告 | 一個焦點色，其餘中性；警示紅固定 | 綠（原版）、藍、墨黑 |
| Apple 發表 | 黑色舞台不動；關鍵字、裝置光、地面光同一組漸層 | 暖橘（原版）、冰藍、翠綠 |
| 插畫場景 | 背景與物件同一色調，整組一起換色相 | 蜜桃（原版）、鼠尾草、天青 |

產生方式：`python3 make_demo.py` 從 `../style-moodboard-v5/src` 複製出各配色版本到 `src/`，再 `node render.cjs` 產生 `img/` 與 `sheet.jpg`。插畫場景的示範是整頁色相旋轉，只為了看效果；正式做法會為每組配色指定顏色。

2026-11-19：Apple 發表的舞台底色從純黑 #000 改成近黑 #0B0B0D（「底色不用純黑」），三張 Apple 示範與 `sheet.jpg` 已重新產生。各風格的正式用色規則見 `../style-specs/`。
