# ROADMAP：deck-architect

> **這是專案唯一的主軸文件。** 每個階段開始前、結束後都回來對照、更新勾選。
> 細節紀錄在 `LOG.md`，目前進度在 `STATUS.md`，兩者都要對齊這份。

## 目標

> **截長補短，做出一個從頭到尾支援全流程的簡報／HTML Skill：**
> **使用者的方法論當骨架，市面頂尖 Skill 的設計美感當皮肉。**

起點：使用者喜歡 codex-ppt-skill 的「圖文融合、說故事感」，但它不會動；HTML 會動，畫面卻不夠活。

## 三個支柱

### ① 方法論（骨架）：來自使用者
見 `inputs/presentation-principles.md`。已用 4 份真實簡報驗證（`inputs/v1-iteration-*.md`）。

- [x] Grill：目的、對象、時長、場合 → 起點與終點；互動表單；既有框架與模板先讀
- [x] 架構：一條軸、單一方向；最上層不可並列；序幕、轉折點、尾聲
- [x] 呈現：標題是路標、重點放大加突出色、不寫過場、目錄與頁籤導航、震撼頁
- [x] 內容可信度：證據、限制、數字查核與出處
- [x] 類型：一頁總覽、可點入附件、進度回報狀態表、多人填寫檢查

### ② 設計美感（皮肉）：借自市面頂尖 Skill
研究見 `inputs/research-html-slide-skills.md`。**借用前先確認授權**：MIT 等寬鬆授權可以借程式碼並標註來源；限制商用或未標授權的只學做法、自己實作。

- [x] **設計系統**：字級比例、網格、留白、配色公式、字體搭配（v2：`assets/base.css`＋5 套主題）
- [x] **風格庫**：依調性分類，附 `avoid_for`（`themes/index.json`）。v2.0 的三選一被使用者退回（只差字體和顏色）；v2.2 把主題改成**構圖**，待使用者確認
- [~] **版型品質**：封面版權列、整塊突出色對比、超大數字與單位、章節浮水印都已升級；待真實簡報驗證
- [ ] **插畫**：先定版位，再生成無字插畫；風格錨點圖；插畫與文字融合
- [ ] **動態背景**：Shader、粒子、ASCII 等，含效能降級；hero 頁與一般頁的遮罩節奏
- [ ] **元素跨頁延續**：交棒、Magic Move，不只導航列
- [ ] **動畫寫法**：遵守 gsap-skills 的禁止清單與無障礙規則
- [x] **排版細節**：中文不用斜體、字距 0、標點擠壓、balance 斷行、等寬數字、對比度檢查

### ③ 全流程（從頭到尾）

- [x] Grill → brief
- [x] 架構展開 → storyboard → lint
- [~] 三選一樣張：5 套構圖不同的主題（v2.2）；待使用者在真實簡報上確認差別夠大
- [x] 製作 → HTML
- [~] 品管：check 有；獨立評審沒有
- [ ] 交付：可編輯 PPTX、講者模式（雙螢幕、計時、排練）
- [ ] 修改：在成品上留言、按 E 直接改字並回寫 storyboard
- [ ] 記憶：外觀帳本、品味記憶、常用風格與模板

- 規則能寫成腳本檢查就寫成腳本；不能檢查的規則不寫。
