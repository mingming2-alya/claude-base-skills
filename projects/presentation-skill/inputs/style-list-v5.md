## 三款重做

- **顧問報告**：從散點圖改成「時程賽跑」。三個方案像跑道一樣排開，一條紅色期限線標出 2028 年第一季的訂單高峰，只有台中的綠色長條在線前結束；另兩案超過期限的部分用斜線標出晚了幾個月。右上角放一個巨大的「6 個月」，下方三條佐證。主張改成「只有台中，趕得上 2028 年的訂單高峰」。
- **日常工作款**：從表格改成便當格，吸收上一輪被移出的便當格的優點。出狀況的專案拿最大一格，附計畫與實際的對照條；準時的專案用進度環；另有本週完成數、下週重點，以及一張橘色的決策卡。
- **攝影雜誌**：改成電影劇照。上下黑邊的寬銀幕畫面裡，一個人站在礁岩上逆光看日出，有變形鏡頭的橫向光暈、光束和底片顆粒。標題做成片名卡，目錄寫成三幕，重點寫成底部字幕，頁籤則是「序幕、第一幕、第二幕、第三幕」。畫面是程式模擬，正式使用換真實照片。

## 2026-11-18 修正一：總結不當主標題

使用者：「12 個風格的總結永遠不該當成主標題，總結只能出現在內文。」

十三張圖原本的結構是「小字標題＋標題下方的巨大總結」，總結看起來就是主標題：插畫場景三種畫風、積木構成三種、水彩水墨三種、Apple 發表、書卷刻本、日常工作款、在地懷舊。全部改成：

- 主標題是這頁的題目，字級最大。例如「第一週會遇到的人」「平台怎麼分工」「兩天一夜怎麼走」「茶從哪裡來」「W46 三個專案的進度」。Apple 發表改用產品名「AI 助理 3.0」當標題，在地懷舊把招牌改寫成「創業五十年」。
- 總結移到內文，字級約是標題的一半，關鍵字仍用突出色。

孔版小誌、摩登金、攝影雜誌、年輕潮流原本就是題目最大，不需要改。

## 2026-11-18 定案：顧問報告走色塊策略

使用者用表單選了 **B 色塊策略**，想保留的元素是「色塊當圖表」「巨大數字」，並補充「數據與證據說話最佳的呈現方式」。合併後的顧問報告（`outputs/style-moodboard-v5/img/06-counsel.jpg`）：

- 色塊高度就是量產月數，數字放大到 C 方向的尺寸。
- 期限線橫切；超過期限的部分打斜線，標出「+5」「+11 個月，錯過高峰」，讓差距直接看得見。
- 左側三條佐證都改成一個大數字配一句說明：30 公里、0 次跨國審批、48 億。
- 標題仍只寫「三個選址方案」，總結在內文。

這款風格的鐵律草案：**每個主張都要有一個數字或證據撐著；圖表本身就是主視覺；只用一個焦點色。** A、C 兩個方向退回，檔案留在 git 歷史。
