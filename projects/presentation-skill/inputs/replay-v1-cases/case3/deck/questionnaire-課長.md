# 給課長的問卷：資訊部年度成果（事業群年終報告・資訊部章節）骨架過目

**目的**：資訊部這一章（部長上台、總經理與各部門主管都在、約 5 分鐘）的骨架已依部長的問卷回覆拍板。請您先過目骨架，並補 3 件承辦人答不出的事實，我們再往下寫每頁內容。
**從**：資訊部（本章簡報承辦人）　**給**：課長　**希望回覆時間**：＿＿月＿＿日前（送出前依年終報告日期填上）
**你的回答會用在**：確認骨架（頁序、頁題、時間配分）；確認第 3 頁的一句話屬實；備好部長被問到客製開發時的回答；定數字的截止日。

## 背景
骨架（事業群模板：章節頁＋3 頁）：章節頁「資訊部」，部長開場：「總經理年初在事業群會議上說，今年資訊部要從後勤變成引擎。」→ ①從後勤到引擎（1 分）：考題的答案 → ②引擎帶來的價值（1.5 分）：AI 客服每年約省 1,800 小時（客服組估算）、資料平台 3 個部門每月查詢 2.1 萬次 → ③基座與明年擴大（2 分）：資安事件 0 件、可用率 99.95% 是底氣，請總經理支持明年資料平台擴大到全事業群的預算。
客製開發依部長決定不上頁面，另做部長小抄備答，不怪需求部門；帳號管理不講。

## 怎麼回答
可以只回答一部分。不確定就寫「不確定」，比猜的答案更有用；要問部長的題目，轉給部長也可以。
